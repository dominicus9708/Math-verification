# Wolfram support material

This directory contains Wolfram-language calculations/support material for the Collatz workspace.

Wolfram outputs follow the same audit rules as Python certificates:

- exact symbolic/integer arithmetic may certify a finite calculation when the script and domain are explicit;
- a numerical plot or decimal experiment is diagnostic unless accompanied by the required rigorous bound;
- finite checks do not establish an infinite theorem by pattern recognition.
