# R1 early formation stabilization before a very late coefficient crossing

Date: 2026-08-12

Status: **exact asymptotic reduction using a standard linear-form lower bound**. It shows that if an R1 first coefficient crossing survives above its start at odd-event depth `H`, then the ordinary starting integer is already fully formed after only `O(log H)` odd events. Thus almost the entire first-crossing prefix lies in the zero-lift actual-orbit regime.

## 1. First coefficient crossing

Let `N` be a renewal floor on a hypothetical nonperiodic no-first-descent orbit. Suppose its first coefficient crossing occurs after `H` odd events and `A` accelerated steps.

Put

\[
\gamma:=\log_2 3.
\]

First crossing gives

\[
\boxed{A=\lceil H\gamma\rceil}
\]

and

\[
\boxed{
\Lambda_H:=A\ln2-H\ln3>0.
}
\]

The contracting coefficient at the crossing is

\[
P:=\frac{2^A}{3^H}=e^{\Lambda_H}>1.
\]

The universal first-crossing correction bound gives

\[
\boxed{
N<\frac{H}{3(P-1)}.
}
\]

## 2. Polynomial lower bound for the nonzero logarithmic form

The algebraic numbers `2` and `3` are multiplicatively independent. Standard Baker--Matveev lower bounds for nonzero linear forms in logarithms therefore imply effective constants

\[
C>0,\qquad c>0
\]

such that for all sufficiently large `H`,

\[
\boxed{
\Lambda_H>cH^{-C}.
}
\]

No optimized value of `C` is required for the structural conclusion below.

Since

\[
e^x-1>x\qquad(x>0),
\]

we have

\[
P-1>\Lambda_H>cH^{-C}.
\]

Consequently

\[
\boxed{
N<\frac{1}{3c}H^{C+1}.
}
\]

Thus every surviving R1 start grows at most polynomially in its first-crossing odd depth.

## 3. Bit-length consequence

Let

\[
B:=\lfloor\log_2N\rfloor+1
\]

be the ordinary binary bit length of the fixed start.

The preceding polynomial bound gives

\[
\boxed{
B\le(C+1)\log_2H+O(1).
}
\]

Therefore

\[
\boxed{B=O(\log H).}
\]

## 4. Formation lift has already ended

The canonical lift-digit theorem gives the exact stabilization bound

\[
\boxed{
t_q=0\qquad\forall q\ge B-1.}
\]

Combining with the bit-length estimate,

\[
\boxed{
t_q=0\qquad\text{for every }q\ge O(\log H).}
\]

Hence among the first `H` odd events leading to the first coefficient crossing, only the initial `O(log H)` events can change the canonical starting residue.

The remaining

\[
\boxed{H-O(\log H)}
\]

odd events are already in the zero-output regime, where the canonical carry is the actual orbit state and

\[
\boxed{2^{v_q}y_{q+1}=3y_q+1.}
\]

## 5. Interpretation

This separates the R1 problem into two very different scales.

### Formation scale

Only `O(log H)` odd events are needed to encode the entire finite ordinary start.

### Dynamical scale

A surviving first coefficient crossing occurs only after `H` odd events, and almost all of those events happen after formation has already frozen.

Therefore an R1 proof cannot work by charging the long near-critical first-crossing prefix to a continuing supply of new start bits. The starting integer has already exhausted its formation information exponentially earlier in event time.

The remaining task is a genuine zero-output orbit-dynamics problem.

## 6. Relation to the finite-support terminal target

The current aperiodic terminal target asks whether a harmonic/critical signed-skew input can produce an eventually zero lift output.

The present theorem shows that in the R1 first-passage subcase, eventual-zero output is not merely eventual: relative to first-crossing depth it begins extremely early,

\[
\boxed{
q_{\mathrm{stabilize}}=O(\log H)=o(H).
}
\]

Any future first-crossing exclusion theorem may therefore assume, after discarding a negligible initial prefix, that the entire long near-critical corridor is generated by one already fixed positive integer.

This is a structural reduction, not an R1 exclusion theorem.
