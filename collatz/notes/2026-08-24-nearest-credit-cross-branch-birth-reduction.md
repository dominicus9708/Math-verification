# Whole-prefix nearest credit reduces to cross-branch birth events

Date: 2026-08-24

Status: **exact algebraic reduction + finite staircase diagnostics.**  This reduces growth of the whole-prefix nearest-root credit to one-step cross-branch Hensel distances.  It does not yet prove a uniform bound for those distances and is not a proof of the Collatz conjecture.

## 1. Complete correction sets

Let

\[
\mathcal C_{H,q}
\]

be the set of affine corrections of all length-\(H\) binary words with exactly \(q\) odd bits, so that

\[
T^H(N)=\frac{3^qN+R}{2^H},\qquad R\in\mathcal C_{H,q}.
\]

Appending one final bit gives the exact set recurrence

\[
\boxed{
\mathcal C_{H+1,q}
=
\mathcal C_{H,q}
\cup
\left(3\mathcal C_{H,q-1}+2^H\right).
}
\]

The first term is the even extension.  The second is the odd extension.

## 2. Nearest complete-prefix credit

For a coefficient-surviving word \(w\) with correction \(R_w\), define

\[
d_{\rm near}(w)
=
\min\left\{
\frac{R'-R_w}{3^q}:R'>R_w,\ R'\in\mathcal C_{H,q},\ R'\equiv R_w\pmod{3^q}
\right\},
\]

when the set is nonempty, and let \(G_H\) be the maximum finite value over coefficient-surviving length-\(H\) words.

Only one positive sibling is required for the smaller-root construction; the full class maximum is unnecessary.

## 3. Terminal maximality implies prefix maximality

Suppose a length-\(H\) prefix has a larger same-\(q\), same-Hensel-class correction difference

\[
R'-R=3^q d,\qquad d>0.
\]

Append an arbitrary common suffix containing \(s\) odd bits.  Correction composition multiplies the prefix difference by \(3^s\), while the total odd count rises from \(q\) to \(q+s\).  Hence the complete-word difference becomes

\[
3^s(R'-R)=3^{q+s}d.
\]

Thus a non-maximal root prefix can never become maximal after a common suffix is appended.

Therefore

\[
\boxed{
\text{whole-prefix maximal at depth }H
\Longrightarrow
\text{whole-prefix maximal at every earlier root prefix.}
}
\]

## 4. Same-final-bit gaps are inherited

Consider a coefficient-surviving word of length \(H+1\) whose depth-\(H\) prefix is already maximal.

If both it and a larger sibling end in `0`, their length-\(H\) prefixes have the same \(q\) and the same correction difference \(3^q d\).  This contradicts maximality of the prefix.

If both end in `1`, write the prefix corrections as \(R,S\) with \(q-1\) odd bits.  The complete corrections are

\[
3R+2^H,\qquad 3S+2^H,
\]

so a complete difference \(3^qd\) is equivalent to the prefix difference

\[
S-R=3^{q-1}d.
\]

Again a genuinely new non-maximality cannot arise inside the same final-bit branch.

Hence:

\[
\boxed{
\text{every new nearest-credit value is born from an opposite-final-bit collision.}
}
\]

All same-branch values are inherited from an earlier horizon and may only decrease when the opposite branch is added.

## 5. Exact cross-branch birth equation

Take the case in which the actual prefix has \(q\) odd bits and the complete word ends in `0`.  Let its correction be

\[
R\in\mathcal C_{H,q}.
\]

An opposite-bit sibling must come from some

\[
S\in\mathcal C_{H,q-1}
\]

and has complete correction

\[
3S+2^H.
\]

A larger same-Hensel sibling with root credit \(d>0\) therefore satisfies exactly

\[
\boxed{
3S+2^H-R=3^qd.
}
\]

Necessarily \(R\equiv2^H\pmod3\), and after division by three,

\[
\boxed{
S
=
\frac{R-2^H}{3}+3^{q-1}d.
}
\]

Thus the birth credit is the smallest positive integer translation, in units of \(3^{q-1}\), that moves the affine target

\[
A_H(R):=\frac{R-2^H}{3}
\]

onto the previous correction set \(\mathcal C_{H,q-1}\).

The opposite orientation (actual word ends in `1`, larger sibling ends in `0`) is the symmetric cross-branch equation

\[
\boxed{
S-(3R+2^H)=3^qd
}
\]

with \(S\in\mathcal C_{H,q}\) and \(R\in\mathcal C_{H,q-1}\).

Therefore the asymptotic nearest-credit problem is no longer a comparison of all pairs of length-\(H\) words.  It is a one-step **cross-branch Hensel covering-radius problem** for the affine targets generated by prefix-maximal coefficient survivors.

## 6. Staircase seen in the exact data

The exact current values are

\[
\boxed{
G_H=
\begin{cases}
1,&6\le H\le18,\\
6,&19\le H\le24,\\
12,&25\le H\le27,\\
25,&28\le H\le29,\\
34,&30\le H\le32.
\end{cases}}
\]

The newly filled finite range \(H=23,\ldots,27\) is certified by

`collatz/src/whole_prefix_nearest_credit_h23_h27_certificate.cpp`.

The \(H=32\) layer-by-layer value

\[
(G_{32,q})_{q=21}^{32}
=(34,25,12,6,6,1,1,1,1,1,0,0)
\]

is certified separately by

`collatz/src/h32_whole_prefix_nearest_credit_certificate.cpp`.

The stepwise persistence is exactly what the inheritance theorem predicts: a value can survive for several horizons without any new cross-branch birth.

The first jump at \(H=19\) coincides with the existing 19-step Sturmian/height-credit macroblock scale.  This is a structural diagnostic, not yet an asymptotic identification theorem.

## 7. New proof target

A sufficient replacement for an all-pairs nearest-credit theorem is now:

> **Cross-branch Hensel covering theorem.**  For every prefix-maximal coefficient-surviving affine target generated by the equations above, the first positive hit in the opposite correction branch occurs at credit
> \[
> d\le H^C
> \]
> for some fixed \(C\), whenever a positive hit exists at all.

Any polynomial bound gives

\[
G_H=H^{O(1)}=2^{o(H)}.
\]

For a fixed hypothetical root \(N\), this keeps every newly born smaller-root credit below \(N\) throughout all sufficiently relevant proof scales, while inherited credits never increase.

The important reduction is that only the cross-branch affine target needs to be controlled; same-final-bit gaps require no new theorem.
