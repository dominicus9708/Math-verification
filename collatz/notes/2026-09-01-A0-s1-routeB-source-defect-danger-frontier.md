## 1. Why a joint frontier is needed

The source Bellman quotient proved that, for one exact future-control state,
only the smallest accumulated normalized defect \(\eta\) matters for the
existence of a low-defect continuation.

Adaptive physical rejection, however, also depends on the source-family lower
endpoint through

\[
\eta_{close}(X_{lo}).
\]

A history with smaller \(\eta\) is harder to reject, and a history with smaller
\(X_{lo}\) is also harder to reject.

Those minima need not occur on the same history.  Therefore a single scalar
minimum is insufficient for exact adaptive physical pruning.

This note gives the exact replacement.

## 2. Exact family key

At one source-refinement layer write

\[
X=r+2^h m,
\qquad
m\in I=[L,U].
\]

The exact key contains

1. every active future-control coordinate;
2. the exact quotient-parameter interval payload \([L,U]\).

For the restricted source/ballot/defect certificate the future control is

\[
(Y,q)
=
(y\bmod2^d,q).
\]

Other predicates may enlarge this key, but the frontier theorem itself is
unchanged.

Histories sharing the key can still have different source residues \(r\) and
different accumulated defects \(\eta\).

## 3. Danger dominance

For two histories sharing the same key, define

\[
(r_1,\eta_1)
\preceq
(r_2,\eta_2)
\]

when

\[
\boxed{
r_1\le r_2,
\qquad
\eta_1\le\eta_2.}
\]

The first pair is more dangerous: it begins at a no-larger ordinary source and
has accumulated no more defect.

The exact retained state is the set of coordinatewise-minimal pairs,

\[
\boxed{
\mathcal F
=
\operatorname{ParetoMin}\{(r,\eta)\}.
}
\]

## 4. Dominance is preserved by every common future refinement

Take the same next parameter bit

\[
\epsilon\in\{0,1\}
\]

from two histories sharing the key.

Because their future control is equal, they emit the same next parity bit.

The source residue update is

\[
\boxed{r'=r+\epsilon2^h.}
\]

Thus

\[
r_1\le r_2
\Longrightarrow
r_1'\le r_2'.
\]

Because the quotient-parameter payload is identical, the child interval
payload generated by the same \(\epsilon\) is also identical.

The emitted parity/rank data are equal, so both histories receive the same
defect increment \(\kappa\):

\[
\boxed{\eta'=\eta+\kappa.}
\]

Hence

\[
\eta_1\le\eta_2
\Longrightarrow
\eta_1'\le\eta_2'.
\]

Therefore

\[
\boxed{
(r_1,\eta_1)\preceq(r_2,\eta_2)
\Longrightarrow
(r_1',\eta_1')\preceq(r_2',\eta_2')
}
\]

for every common future parameter suffix.

This makes Pareto deletion permanent and exact.

## 5. Compatibility with the physical threshold

For a shared interval payload with lower quotient endpoint \(L\), the ordinary
family lower source is

\[
\boxed{X_{lo}=r+2^hL.}
\]

Thus

\[
r_1\le r_2
\Longrightarrow
X_{lo,1}\le X_{lo,2}.
\]

The previously proved inverse defect budget is monotone in the opposite
direction:

\[
X_{lo,1}\le X_{lo,2}
\Longrightarrow
\eta_{close}(X_{lo,1})
\ge
\eta_{close}(X_{lo,2}).
\]

Suppose pair 2 is not physically closed:

\[
\eta_2<\eta_{close}(X_{lo,2}).
\]

For a dominating pair 1,

\[
\eta_1\le\eta_2
<
\eta_{close}(X_{lo,2})
\le
\eta_{close}(X_{lo,1}),
\]

so pair 1 is also not closed.

Conversely, if the harder pair 1 is closed, pair 2 is necessarily closed.

Therefore a dominated pair can never be the unique physical survivor and may
be discarded exactly.

## 6. Frontier geometry

After sorting by increasing \(r\), every retained frontier must have strictly
decreasing \(\eta\).

Otherwise a later point with

\[
r_2>r_1,
\qquad
\eta_2\ge\eta_1
\]

would be dominated.

Thus the frontier is an antichain staircase:

\[
\boxed{
r\uparrow\quad\Longrightarrow\quad\eta\downarrow.}
\]

This shape is exact, but no horizon-independent bound on its number of corners
is yet proved.

## 8. Relation to the four-state interval theorem

For a fixed parent interval and refinement depth, the existing interval theorem
shows that quotient-parameter payloads occupy at most four exact states.

The new architecture is therefore

\[
\boxed{
\text{future control}
\times
\text{one of a few exact interval payloads}
\times
\text{Pareto frontier in }(r,\eta).
}
\]

The interval explosion is already closed.  The newly exposed complexity is the
frontier width.

This is substantially cleaner than carrying every raw source residue history.

## 9. Active-predicate rule

The frontier theorem is exact only when histories in one key agree on every
predicate coordinate that can affect future acceptance.

If the active decoder also queries

- correction residue;
- checkpoint residue;
- projective carry;
- critical phase;
- renewal/C4F information;

those coordinates must be inserted into the key before Pareto comparison.

Once inserted, the same \((r,\eta)\) dominance argument remains valid because
common future transitions still add identical residue and defect increments to
pairs in the same exact key.
