# G81 conjugacy fibre, Hensel ultrametric, and neutral integerization

Date: 2026-08-14

Status: **exact finite conjugacy classification + exact correction/valuation theorem + proof-strategy limitation**. This refines the type-0 gate renormalization. It does not prove the Collatz conjecture.

Put

\[
\alpha:=\log_3 2,
\qquad
\varepsilon:=12-19\alpha,

## 1. Exact conjugacy count

Use the convergent bounds

\[
\boxed{
\frac{15601}{24727}<\alpha<\frac{31867}{50508}
}
\]

certified equivalently by

\[
3^{15601}<2^{24727},
\qquad
3^{31867}>2^{50508}.
\]

For a length-`L` Sturmian factor beginning at phase `x`, discontinuities occur at

\[
p_j=\lceil j\alpha\rceil-j\alpha,
\qquad 1\le j\le L.
\]

The rational bounds above determine every `ceil(j alpha)` and the sign of the gate-interval inequalities for all `j<=1558` without floating-point arithmetic.

The result is

\[
\boxed{G_{81}\text{ has exactly }19\text{ conjugate factor types},}
\]

and

\[
\boxed{G_{82}\text{ has exactly one factor type}.}
\]

Thus the 81-gate retains a finite conjugacy fibre, while the 82-gate is phase-rigid at the original parity-word level.

## 2. Exact discontinuity lattice inside G81

Order the 19 `G_81` factors by increasing phase:

\[
W_0,W_1,\ldots,W_{18}.
\]

Between consecutive factors there are 18 discontinuities. They are indexed by

\[
\boxed{
 j_{3a+b}=1054+84a-485b,
 \qquad
 a=0,\ldots,5,
 \quad b=0,1,2.
}
\]

At these positions

\[
\boxed{
 d_{3a+b}:=\lceil j_{3a+b}\alpha\rceil
 =665+53a-306b.
}
\]

Since every `G_81` factor has total odd count `q=971`, define the suffix odd count

\[
\boxed{
 r_{3a+b}:=971-d_{3a+b}
 =306-53a+306b.
}
\]

The vectors `(84,53)`, `(485,306)`, and `(1054,665)` are consecutive continued-fraction lattice data for `alpha`; in particular

\[
53\cdot485-306\cdot84=1,
\qquad
665\cdot485-306\cdot1054=1.
\]

Hence the internal gate conjugacy is itself generated by the continued-fraction lattice.

## 3. One adjacent swap and one pure correction channel

Crossing one discontinuity changes exactly one adjacent pair

\[
01\longrightarrow10
\]

at zero-based positions `j-1,j`.

If `r` odd symbols lie strictly after that pair, the affine correction changes by

\[
\boxed{
R(01)-R(10)=2^{j-1}3^r.
}
\]

Therefore for the gate chain

\[
\boxed{
R(W_i)-R(W_{i+1})
=2^{j_i-1}3^{r_i},
}
\]

and

\[
\boxed{
v_3(R(W_i)-R(W_{i+1}))=r_i.}
\]

The normalized rational start displacement is

\[
\frac{R(W_i)-R(W_{i+1})}{3^{971}}
=
\frac{2^{j_i-1}}{3^{d_i}}.
\]

Since `d_i-j_i alpha=p_{j_i}`,

\[
\boxed{
\frac{2^{j_i-1}}{3^{d_i}}
=\frac12\,3^{-p_{j_i}}.
}
\]

Thus every adjacent conjugacy displacement is positive and less than `1/2`; across the full 18-edge chain the total rational displacement is less than `9`.

## 4. Exact 3-adic ultrametric on the conjugacy chain

All 18 valuations `r_i` are distinct. For `i<k`,

\[
R(W_i)-R(W_k)
=
\sum_{t=i}^{k-1}2^{j_t-1}3^{r_t}.
\]

The summand with smallest `r_t` is unique and its coefficient is a 3-adic unit. Therefore no cancellation can raise the valuation:

\[
\boxed{
 v_3(R(W_i)-R(W_k))
 =\min_{i\le t<k}r_t.
}
\]

Hence the entire correction-congruence geometry of the 19 conjugates is encoded by the 18 edge labels `r_i`; no large correction integers are needed.

## 5. Nested survival chain

For one adjacent change `01 -> 10`, the cumulative mechanical odd-count boundary is unchanged before the pair and after the pair, but is larger by exactly one at the intermediate time.

Consequently, for any fixed incoming relative slack `h` and any actual parity word `v`, if `v` survives relative to the later-phase mechanical factor `10`, then it also survives relative to the earlier-phase factor `01`.

Thus

\[
\boxed{
\mathcal S_h(W_0)
\supseteq
\mathcal S_h(W_1)
\supseteq\cdots\supseteq
\mathcal S_h(W_{18}).
}
\]

The final relative displacement `Sigma` is unchanged because all conjugates have the same total odd count. Only the internal minimum `M` can become one unit more restrictive at each adjacent swap.

Therefore the 19-factor gate fibre is not an arbitrary phase family: it is an ordered monotone survival chain equipped with an exact 3-adic ultrametric.

## 6. Why conjugate Hensel integerization is neutral

Take `W_i` as a higher-correction alternate word and `W_k`, `i<k`, as the lower-correction actual word. Let `j_*` be the largest swap position among the edges `i,...,k-1`.

Because

\[
d=\lceil j\alpha\rceil
\]

is strictly increasing with `j`, the largest `j_*` has the smallest suffix odd count `r_*`; by Section 4 it determines the full 3-adic valuation.

After the adjacent pair at `j_*`, all differing swap positions have already occurred and the two conjugate words have an identical remaining suffix. The rational alternate-start displacement therefore loses its final odd denominator exactly when that last differing pair is completed.

At that moment the alternate branch and the actual branch are already at the **same ordinary state**. Hence this Hensel integerization does not create a new smaller ordinary predecessor independently of the actual trajectory:

\[
\boxed{
\text{conjugate-gate integerization}
=\text{re-encoding of the actual state after the last differing swap}.
}
\]

If that state is below the original minimum, the actual trajectory itself has already achieved first descent. If it is not below the minimum, the conjugate alternate gives no additional contradiction.

Thus the beautiful conjugacy/Hensel structure is a state-compression theorem, not by itself an R2 elimination theorem.

## 7. Strategic consequence

At the 81/82 gate scale one may retain the compact state

\[
\boxed{
(\text{gate type},\text{phase-chain index},\Sigma,M,\text{Hensel edge labels})
}
\]

instead of a length-1500 parity word.

However a genuine new minimality obstruction must use at least one ingredient outside the conjugate gate fibre:

1. a same-`q` alternate word outside the conjugacy chain;
2. the same-integer dyadic canonical-address condition;
3. the ternary recursively-sufficient address;
4. or an independent headroom/Archimedean bound.

This prevents an invalid proof that mistakes Sturmian conjugacy swaps for new smaller-predecessor information.
