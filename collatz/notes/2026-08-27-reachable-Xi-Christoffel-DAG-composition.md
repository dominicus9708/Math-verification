# Reachable-Xi Christoffel-DAG composition

Date: 2026-08-27

Status: **SAFE exact control-language composition theorem.** This removes the intermediate Hensel carry from the raw reachable-set DAG. It does not prove the Collatz conjecture.

## 1. Raw ordered-control invariant set

Traverse a gap block `w=(g_1,...,g_h)` from right to left. For a displacement word `d=(d_1,...,d_h)` satisfying

\[
d_i\ge \max\{0,d_{i-1}-g_i+1\}
\]

with prescribed right ordering input `p_R=d_0` and prescribed left output `p_L=d_h`, define

\[
\Xi_w(d):=-\sum_{i=0}^{h-1}3^i2^{e_i-d_{i+1}}.
\]

Let

\[
\boxed{\mathcal R_w(p_R,p_L)}
\]

be the set of all such raw invariant values generated by the ordered displacement controls. No Hensel boundary carry is imposed in the definition of this set.

This is intentional. For a complete physical block, once a control word satisfies the exact full two-boundary invariant equation, the previous invariant theorem recovers every local Hensel division automatically.

## 2. Exact concatenation

Let `w=uv`, where `u` of length `r` is traversed first and `v` of length `s` is traversed second. For one complete control word let `p` be the displacement at the interface.

The raw Hensel invariant obeys

\[
\boxed{\Xi_{uv}=\Xi_u+3^r\Xi_v.}
\]

Therefore the reachable sets satisfy the exact set-valued convolution

\[
\boxed{
\mathcal R_{uv}(p_R,p_L)
=
\bigcup_{p\ge0}
\left(
\mathcal R_u(p_R,p)
+3^r\mathcal R_v(p,p_L)
\right).
}
\]

Here `+` is Minkowski addition of subsets of the ambient dyadic-rational/3-adic coefficient ring.

### Proof

Every full ordered control word restricts uniquely to a control word on `u`, a shared interface displacement `p`, and a control word on `v`, so the left-hand set is contained in the right-hand union.

Conversely, concatenate any ordered word from `R_u(p_R,p)` with any ordered word from `R_v(p,p_L)`. The shared `p` is exactly the ordering memory required at the first action of `v`, so the concatenation is ordered. Direct splitting of the invariant sum gives `Xi_u+3^r Xi_v`. Hence every element on the right is realized by a full ordered control word.

No intermediate Hensel carry is required for this raw control-language identity.

## 3. Why this does not violate the earlier subblock caveat

The earlier audit correctly warned that `Xi` alone is not automatically a complete state for an arbitrary **prescribed-boundary subblock operator**. Two independently prescribed subblocks must share the same intermediate carry.

The object here is different:

\[
\boxed{\text{raw ordered-control reachable set before physical boundary matching}.}
\]

We do not assign an independent Hensel boundary to either child. After the complete control word is assembled, one global equality

\[
\Xi_w(d)=\Xi_w^{\rm phys}
\]

is imposed. The exact full-block invariant theorem then reconstructs the unique intermediate carry sequence and proves all Hensel divisions.

Thus the logically safe order is

\[
\text{ordered controls}
\to\mathcal R_w
\to\text{global physical Xi match}
\to\text{Hensel carry reconstruction}.
\]

## 4. Defect-coordinate version

Let

\[
\Delta\Xi_w:=\Xi_w-\Xi_w^{(0)}.
\]

Because the mechanical invariant obeys the same concatenation,

\[
\boxed{
\Delta\Xi_{uv}
=
\Delta\Xi_u+3^r\Delta\Xi_v.
}
\]

If each child is instead renormalized at its own right boundary to the min-plus defect coordinate `J`, the equivalent law is

\[
\boxed{J_{uv}=J_u+\lambda(u)J_v,}
\]

with

\[
\lambda(u)=3^{|u|}/2^{G(u)}.
\]

These are the same identity in two different coordinate normalizations. The factor `3^r` belongs to raw `Xi`; the factor `lambda(u)` belongs to locally renormalized real defect cost. They must not be interchanged.

The anchored first-resonance mechanical word already has a 138-node Farey/Christoffel DAG. For every node `W=UV`, the new exact operator is

\[
\boxed{

The carry dimension has disappeared from the raw DAG.

## 7. DSD audit
