# Survivor prefix tree and bounded-formation-floor criterion

Date: 2026-08-11

Status: **exact global reformulation**. This note identifies which infinite parity paths are relevant to ordinary positive-integer counterexamples and explains why finite local pattern exclusion cannot by itself finish the proof.

## 1. Prefix tree

Let

\[
\Omega_k:=\{0,1\}^k
\]

be the set of accelerated Collatz parity words of length `k`, and let

\[
\Omega:=\{0,1\}^{\mathbb N}
\]

be the infinite binary path space.

Every finite parity word determines one residue class modulo `2^k`. Equivalently, for the normalized affine prefix state

\[
T^k(n)=a_k(n+c_k),
\]

formation is given by

\[
\boxed{n\equiv-c_k\pmod{2^k}.}
\]

Thus every finite parity word is locally realizable by a congruence class of integers. The proof problem cannot be solved merely by declaring sufficiently complicated finite parity patterns impossible.

---

## 2. Formation floor

For a finite word `w` of length `k`, define

\[
\boxed{
\rho_k(w)
:=
\min\{n\ge2:n\text{ realizes }w\}.
}
\]

If `w'` extends `w`, then the corresponding residue class is nested inside the parent class, so

\[
\boxed{
\rho_{k+1}(w')\ge\rho_k(w).
}
\]

Therefore along every infinite path `omega in Omega`,

\[
\rho_1(\omega)\le\rho_2(\omega)\le\cdots
\]

is a nondecreasing sequence of positive integers.

---

## 3. Finite-natural realizability criterion

### Theorem

An infinite parity path `omega` is generated by one fixed finite positive integer `n>=2` if and only if its formation floors are bounded:

\[
\boxed{
\sup_k\rho_k(\omega)<\infty.
}
\]

Equivalently, because `rho_k` is an integer-valued nondecreasing sequence,

\[
\boxed{
\rho_k(\omega)\text{ is eventually constant.}
}
\]

### Proof

If a fixed finite integer `n` generates the path, then every prefix residue class contains `n`, so

\[
\rho_k(\omega)\le n
\]

for every `k`. Once `2^k>n`, the least nonnegative representative of the class is `n` itself, hence `rho_k=n` thereafter.

Conversely, suppose `rho_k` is bounded. Since it is nondecreasing and integer-valued, there are `K` and `n` such that

\[
\rho_k=n
\qquad(k\ge K).
\]

By definition, `n` belongs to every corresponding nested prefix class from depth `K` onward, hence realizes every finite prefix of `omega`; therefore its accelerated Collatz parity sequence is exactly `omega`.

## 4. Survival ceiling

For each finite prefix `w`, let

\[
\Theta_k(w)
\]

be the cumulative survival ceiling obtained from all contracting prefix endpoints:

\[
\Theta_k(w)
=
\min_{\substack{1\le j\le k\\a_j<1}}
\frac{a_jc_j}{1-a_j},
\]

with `Theta_k=+infinity` when no contracting prefix endpoint has occurred.

The prefix contains at least one start with no first descent through depth `k` if and only if

\[
\boxed{
\rho_k(w)\le\Theta_k(w).
}
\]

Along path extension,

\[
\boxed{
\Theta_{k+1}\le\Theta_k.
}
\]

---

## 5. Survivor prefix tree

Define the survivor tree

\[
\boxed{
\mathcal T
:=
\{w:\rho(w)\le\Theta(w)\}.
}
\]

A node belongs to `T` exactly when its parity class contains at least one positive integer that has not descended below its own start through that prefix.

This tree is prefix-closed: if a child survives all constraints through depth `k+1`, its parent survives all constraints through depth `k`.

---

## 6. Bounded-floor counterexample theorem

### Theorem

The Collatz conjecture for positive integers is equivalent to the statement

\[
\boxed{
\text{every infinite branch }\omega\text{ of }\mathcal T
\text{ satisfies }\rho_k(\omega)\to\infty.
}
\]

Equivalently, a counterexample exists if and only if the survivor tree contains an infinite branch with bounded formation floor.

### Proof

If `n>=2` is a counterexample to first descent, its actual parity prefixes are all survivor nodes, and for sufficiently large `k` their formation floor equals `n`. Hence there is a bounded-floor infinite branch.

Conversely, suppose `omega` is an infinite survivor branch and `rho_k(omega)` is bounded. By the finite-natural realizability theorem, `rho_k` eventually stabilizes at one finite integer `n`. Since every prefix is a survivor node,

\[
n=\rho_k\le\Theta_k
\]

for every sufficiently large `k`, and the same `n` realizes every prefix. Therefore `T^j(n)>=n` for all `j`, so `n` has infinite first-descent time and is a counterexample.

## 7. Fixed-bound finite-subtree criterion

For `N>=2`, define

\[
\boxed{
\mathcal T_{\le N}
:=
\{w\in\mathcal T:\rho(w)\le N\}.
}
\]

Because the full prefix tree is binary, `T_{<=N}` is finitely branching.

There is a counterexample `n<=N` if and only if `T_{<=N}` has an infinite branch. By Koenig's lemma, this is equivalent to `T_{<=N}` having nodes at arbitrarily large depth.

Hence

\[
\boxed{
\text{Collatz}
\iff
\forall N\ge2,\ \mathcal T_{\le N}\text{ is finite}.
}
\]

Equivalently, for every finite bound `N` there is a finite depth `K(N)` such that

\[
\boxed{
\rho(w)>N
\quad\text{for every survivor node }w\text{ of depth }K(N).
}
\]

This is the path-space version of global frontier escape.

## 8. Why local finite-pattern filters are insufficient

The 2-adic extension of the Collatz map gives a one-to-one correspondence between 2-adic starting states and infinite parity sequences. Consequently, arbitrarily long finite parity or macroblock prefixes are natural objects of the exact dynamics and cannot in general be excluded merely because of their local pattern.

The property needed to distinguish ordinary positive integers from generic 2-adic paths is global:

\[
\boxed{
\text{ordinary finite integer}
\iff
\text{bounded/eventually constant formation floor}.
}
\]

Therefore the final attribute frame must retain information capable of proving one of the following along every infinite survivor branch:

1. formation-floor escape,
   \[
   \rho_k\to\infty;
   \]
2. survival-bound crossing,
   \[
   \rho_k>\Theta_k
   \]
   at some finite depth.

Any attribute that only classifies a fixed finite suffix or macroblock pattern is auxiliary unless it feeds one of these two global conclusions.

## 9. Final two-boundary theorem target

The proof problem can now be stated on path space without reference to a numerical search cutoff.

### Two-Boundary Escape Target

For every infinite parity path `omega`, prove

\[
\boxed{
\rho_k(\omega)\to\infty
\quad\text{or}\quad
\exists K:\rho_K(\omega)>\Theta_K(\omega).
}
\]

A path of the first type is a valid 2-adic/parity path but does not correspond to any fixed finite positive integer. A path of the second type is eliminated by first descent. A counterexample would have to evade both alternatives simultaneously.

This is the global theorem that later resource, valuation, resonance, and generating-function arguments must serve.
