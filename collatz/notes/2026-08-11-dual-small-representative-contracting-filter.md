# Dual small-representative filter at contracting checkpoints

Date: 2026-08-11

Status: **exact necessary-condition theorem** for a nonperiodic positive-integer no-first-descent orbit. It combines finite-natural start formation with the harmonic correction corridor to obtain simultaneous small representatives at the 2-adic start and 3-adic endpoint sides.

## 1. Exponent-code identity

For `q` odd events let

\[
A_q=\sum_{i=0}^{q-1}v_i
\]

and

\[
B_q=\sum_{i=0}^{q-1}3^{q-1-i}2^{A_i}.
\]

Then

\[
\boxed{
2^{A_q}x_q=3^q n+B_q.
}
\]

The normalized correction is

\[
c_q=\frac{B_q}{3^q}.
\]

---

## 2. Exact 2-adic start representative

The completed exponent code satisfies

\[
3^q n+B_q
\equiv
2^{A_q}
\pmod{2^{A_q+1}}.
\]

Therefore

\[
\boxed{
n
\equiv
2^{A_q}-3^{-q}B_q
\pmod{2^{A_q+1}}.}
\]

For a code generated by one fixed finite start `n`, once

\[
2^{A_q+1}>n,
\]

the least positive representative of this start residue is exactly the constant `n`.

Thus the 2-adic start side has bounded representative:

\[
\boxed{r_2(q)=n=O_n(1).}
\]

---

## 3. Exact 3-adic endpoint representative

Reduce the exponent-code identity modulo `3^q`:

\[
2^{A_q}x_q\equiv B_q\pmod{3^q}.
\]

Since `2` is invertible modulo `3^q`,

\[
\boxed{
x_q
\equiv
2^{-A_q}B_q
\pmod{3^q}.}
\]

Let `r_3(q)` denote the least positive representative of the residue on the right.

For every fixed finite start, the elementary event bound

\[
x_q+1\le(n+1)(3/2)^q
\]

implies `x_q<3^q` for all sufficiently large `q`. Hence eventually

\[
\boxed{r_3(q)=x_q.}
\]

---

## 4. Polynomial endpoint squeeze at contraction

Assume the orbit is nonperiodic and never descends below `n`. The harmonic correction theorem gives

\[
\boxed{c_q=O_n(q^{1/9}).}
\]

At a contracting checkpoint,

\[
\lambda_q=\frac{2^{A_q}}{3^q}>1.
\]

Using

\[
x_q=\frac{n+c_q}{\lambda_q},
\]

we get

\[
\boxed{
x_q<n+c_q=O_n(q^{1/9}).}
\]

Therefore every sufficiently large contracting checkpoint satisfies

\[
\boxed{
r_3(q)=O_n(q^{1/9}).}
\]

At the same time its real drift condition is

\[
\boxed{A_q>q\log_2 3.}
\]

---

## 5. Contracting-code squeeze

A hypothetical nonperiodic no-first-descent positive-integer orbit must therefore have, at every sufficiently large contracting checkpoint, an exponent code satisfying simultaneously:

\[
\boxed{
\begin{aligned}
&r_2(q)=n=O_n(1),\\
&r_3(q)=O_n(q^{1/9}),\\
&A_q>q\log_2 3.
\end{aligned}
}
\]

The first condition is finite-natural 2-adic stabilization. The second is a nontrivial Archimedean consequence of no first descent and nonperiodicity. The third places the checkpoint on the contracting side of the real drift boundary.

This gives a concrete symbolic filtering target that is strictly stronger than merely requiring a valid finite exponent code.

---

## 6. Remaining theorem target

The next number-theoretic question can be stated without enumerating starting integers:

> Can an infinite nested exponent code have infinitely many indices `q` for which its exact 2-adic start representative is one fixed positive integer, its exact 3-adic endpoint representative is only polynomial in `q`, and its real drift is contracting?

A universal negative answer would eliminate the recurrent-contracting nonperiodic hard core. No such exclusion theorem is proved here.
