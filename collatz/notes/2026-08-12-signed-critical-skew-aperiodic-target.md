# Signed critical Beatty skew formulation for the full aperiodic branch

Date: 2026-08-12

Status: **exact necessary-condition reduction for every nonperiodic positive-integer first-descent counterexample**. It recombines R1 and R2 into one signed skew language. It is not yet an exclusion theorem.

## 1. Universal signed skew coordinate

Let

\[
x_{i+1}=\frac{3x_i+1}{2^{v_i}},
\qquad v_i\ge1,
\]

be the odd-event Syracuse trajectory from a positive renewal floor `N` on a hypothetical nonperiodic first-descent counterexample.

Put

\[
A_i:=\sum_{j<i}v_j,
\qquad
\gamma:=\log_2 3,
\qquad
A_i^*:=\lfloor i\gamma\rfloor.
\]

Define the signed displacement

\[
\boxed{s_i:=A_i^*-A_i\in\mathbb Z.}
\]

Unlike the R2-only formulation, `s_i` is now allowed to be negative.

The fixed Beatty/Sturmian driver is

\[
\boxed{
r_i:=A_{i+1}^*-A_i^*\in\{1,2\}.
}
\]

Exactly as before,

\[
\boxed{v_i=s_i+r_i-s_{i+1}.}
\]

Thus local admissibility `v_i>=1` is equivalent to

\[
\boxed{s_{i+1}\le s_i+r_i-1.}
\]

There is no independent lower bound on `s_{i+1}` at the local-code level. Negative `s` means that the pure multiplicative coefficient has crossed to the contracting side.

## 2. Exact coefficient and correction in signed coordinates

Since

\[
A_i=i\gamma-\{i\gamma\}-s_i,
\]

we have

\[
\boxed{
\lambda_i:=\frac{2^{A_i}}{3^i}
=2^{-\{i\gamma\}-s_i}.
}
\]

The odd-event affine correction is

\[
\boxed{
c_q
=\frac13\sum_{i=0}^{q-1}
2^{-\{i\gamma\}}2^{-s_i}.
}
\]

The realized odd-event state is

\[
\boxed{
x_q=\frac{N+c_q}{\lambda_q}.}
\]

These identities hold whether `s_q` is positive, zero, or negative.

## 3. Harmonic theorem gives a universal signed-skew mass bound

The previously proved harmonic theorem applies to **every** nonperiodic positive-integer no-first-descent survivor, not only to R2. It gives

\[
\boxed{c_q=O_N(q^{1/9}).}
\]

Because

\[
\frac12<2^{-\{i\gamma\}}\le1,
\]

we obtain

\[
\boxed{
\sum_{i<q}2^{-s_i}=O_N(q^{1/9}).
}
\]

Thus the same skew-mass estimate controls both the coefficient-survival side and all coefficient-crossing excursions.

## 4. Negative excursions are automatically shallow and sparse

Let

\[
\sum_{i<q}2^{-s_i}\le K_Nq^{1/9}
\]

for all sufficiently large `q`.

For a single index `i<q`,

\[
2^{-s_i}\le K_Nq^{1/9}.
\]

Taking `q=i+1` gives

\[
\boxed{
s_i\ge-\frac19\log_2(i+1)-O_N(1).}
\]

So a no-first-descent counterexample can cross to the negative/coefficient-contracting side only logarithmically deeply.

More generally, for any real threshold `u`,

\[
\#\{i<q:s_i\le u\}
\le
2^uK_Nq^{1/9}.
\]

In particular, for every fixed `M>=0`,

\[
\boxed{
\#\{i<q:s_i\le M\}=O_N(2^Mq^{1/9}),
}
\]

and hence this set has density zero.

For every fixed `theta<8/9`,

\[
\boxed{
\frac1q\#\{i<q:s_i\le\theta\log_2q\}\to0.
}
\]

Therefore **every** aperiodic counterexample, including recurrent R1-type coefficient crossings, spends density one of its odd events far on the positive coefficient-survival side.

R1 crossings can occur only in a sparse exceptional set of event indices.

## 5. Displacement-area lower bound

By Jensen,

\[
2^{-\frac1q\sum_{i<q}s_i}
\le
\frac1q\sum_{i<q}2^{-s_i}.
\]

Hence

\[
\boxed{
\sum_{i<q}s_i
\ge
\frac89q\log_2q-O_N(q).
}
\]

This signed-area estimate again applies to the full aperiodic branch.

## 6. Critical-density boundary

For a positive ordinary integer with a noncyclic divergent trajectory, the López--Stoll critical-density theorem forces the lower parity density to equal

\[
\frac{\ln2}{\ln3}.
\]

In the odd-event exponent coordinates this is equivalent to

\[
\limsup_{q\to\infty}\frac{A_q}{q}=\gamma.
\]

Since

\[
A_q=\lfloor q\gamma\rfloor-s_q,
\]

and the harmonic bound already prevents `s_q/q` from having a negative linear limit, we obtain the necessary critical recurrence

\[
\boxed{
\liminf_{q\to\infty}\frac{s_q}{q}=0.
}
\]

Thus the signed path has large positive displacement in density one, only shallow sparse negative excursions, yet returns to sublinear relative height infinitely often.

## 7. Exact 2-adic naturalness map

For any locally admissible infinite signed path define

\[
A_i=\lfloor i\gamma\rfloor-s_i.
\]

The local condition `v_i>=1` implies `A_i>=i`, so `A_i->infinity`. Hence the Bernstein series converges in `Z_2`:

\[
\boxed{
\Phi(s)
:=-\sum_{i=0}^{\infty}
\frac{2^{\lfloor i\gamma\rfloor-s_i}}{3^{i+1}}
\in\mathbb Z_2.
}
\]

If the skew path is generated by one fixed positive integer start `N`, then exactly

\[
\boxed{
\Phi(s)=N\in\mathbb N_{>1}.
}
\]

As in the R2-only case, every finite signed-skew prefix is locally realizable by a dyadic residue class. The genuinely global condition is that the infinite 2-adic limit be one fixed positive ordinary integer.
