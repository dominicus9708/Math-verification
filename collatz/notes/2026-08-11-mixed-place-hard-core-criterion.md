# Mixed-place hard-core criterion

Date: 2026-08-11

Status: **exact hard-core reformulation with standard 2-adic conjugacy input**. This note identifies the remaining nonperiodic positive-integer counterexample as a simultaneous 2-adic naturality and Archimedean survival problem.

## 1. Why an integer counterexample must start odd

For the accelerated Collatz map

\[
T(n)=\begin{cases}
n/2,&n\text{ even},\\
(3n+1)/2,&n\text{ odd},
\end{cases}
\]

any even `n>1` descends immediately. Therefore a first-descent counterexample must be odd.

For an odd state `x_q`, define

\[
v_q:=v_2(3x_q+1)
\]

and the odd-to-odd Syracuse event map

\[
\boxed{
x_{q+1}=\frac{3x_q+1}{2^{v_q}}.}
\]

Between two successive odd event states, the intermediate accelerated iterates are obtained by repeated division by two and are all at least the final odd state. Hence for an odd initial `n`,

\[
\boxed{
T^k(n)\ge n\text{ for every accelerated step }k
}
\]

is equivalent to

\[
\boxed{
x_q\ge n\text{ for every odd-event index }q.}
\]

## 2. Event-prefix affine coordinates

Let

\[
A_q:=\sum_{i=0}^{q-1}v_i,
\qquad
\lambda_q:=\frac{2^{A_q}}{3^q}.
\]

Let `d_i` be the accelerated-step position of the `i`th odd parity bit. At odd-event checkpoints these positions are

\[
d_i=A_i.
\]

Define the positive real partial correction

\[
\boxed{
c_q:=\sum_{i=0}^{q-1}\frac{2^{A_i}}{3^{i+1}}.}
\]

Then the exact odd-event affine formula is

\[
\boxed{
x_q=\frac{n+c_q}{\lambda_q}.}
\]

Therefore the no-descent condition is

\[
\boxed{
\lambda_q\le1+\frac{c_q}{n}
\qquad\text{for every }q.
}
\]

This is the Archimedean survival inequality.

## 3. The same correction as a 2-adic formation coordinate

For a parity vector

\[
v=\sum_{i\ge0}2^{d_i}\in\mathbb Z_2,
\]

the standard inverse 3x+1 conjugacy map is

\[
\boxed{
\Phi(v)
=-\sum_{i=0}^{\infty}\frac{2^{d_i}}{3^{i+1}}
}
\]

with convergence in the 2-adic metric.

Thus the finite sums satisfy

\[
\boxed{
-c_q
=-\sum_{i=0}^{q-1}\frac{2^{A_i}}{3^{i+1}}
}
\]

and are exactly the finite 2-adic formation approximants associated with the event parity prefix.

For the parity vector of a fixed starting integer `n`, the 2-adic conjugacy gives

\[
\boxed{
-c_q\longrightarrow n
\qquad\text{in }\mathbb Z_2.
}
\]

Equivalently, the formation floors stabilize to `n`, or the formation-increment bits are eventually zero.

## 4. Mixed-place characterization of a nonperiodic counterexample

A nonperiodic positive-integer first-descent counterexample would therefore supply an odd integer `n>=3` and an aperiodic parity/event sequence satisfying simultaneously:

### 2-adic naturality

\[
\boxed{
-c_q\to n
\quad\text{in }\mathbb Z_2.
}
\]

### Real no-descent

\[
\boxed{
\lambda_q\le1+\frac{c_q}{n}
\quad\text{for every }q.
}
\]

### Exact event arithmetic

\[
\boxed{
\lambda_q=\frac{2^{A_q}}{3^q},
\qquad
c_q=\sum_{i<q}\frac{2^{A_i}}{3^{i+1}},
}
\]

with strictly increasing integer positions `A_i` generated by positive valuations `v_i=A_{i+1}-A_i`.

Thus the remaining hard core is a simultaneous compatibility problem between two places:

\[
\boxed{
\text{2-adic convergence to a positive ordinary integer}
+
\text{Archimedean survival inequalities}.
}
\]

## 5. Periodic versus aperiodic branch

If the parity sequence is periodic and a prefix returns the actual orbit state to `n`, then a contracting prefix ceiling satisfies

\[
C=n,
\]

and the problem is a nontrivial positive cycle problem.

If the parity sequence is aperiodic and corresponds to a rational 2-adic integer (in particular an ordinary positive integer), then the orbit is noncyclic. Existing 2-adic parity-density results place such a hypothetical trajectory on the critical odd-density boundary.

The present framework therefore keeps the two failure modes distinct while using the same formation coordinate `c`:

- periodic: exact fixed-point equality;
- nonperiodic: mixed-place critical hard core.

## 7. Scope and literature positioning

The use of parity vectors and the 2-adic conjugacy map is standard and should not be presented as new. The present contribution of the proof architecture is the way the same finite correction sums are assigned two simultaneous roles:

1. their negative values are 2-adic formation approximants;
2. their positive real values enter the exact no-descent budget.

The research question is therefore not whether the conjugacy exists, but whether these two roles can be shown to be incompatible for an aperiodic survivor corresponding to a positive ordinary integer.
