# Harmonic mixed-place exclusion target

Date: 2026-08-11

Status: **consolidated final theorem target for the nonperiodic branch**. All implications leading to this target are necessary-condition reductions; the exclusion theorem itself is not proved.

## 1. Exponent-position state

Let

\[
0=A_0<A_1<A_2<\cdots,
\]

with positive integer gaps

\[
v_i=A_{i+1}-A_i\ge1.
\]

Define

\[
\boxed{
\lambda_i:=\frac{2^{A_i}}{3^i}
}
\]

and the partial correction series

\[
\boxed{
c_q
:=
\sum_{i=0}^{q-1}\frac{2^{A_i}}{3^{i+1}}
=
\frac13\sum_{i=0}^{q-1}\lambda_i.
}
\]

## 2. Finite-natural 2-adic condition

The standard inverse parity/exponent conjugacy associates the infinite code with the 2-adic value

\[
\boxed{
-\sum_{i=0}^{\infty}\frac{2^{A_i}}{3^{i+1}}.
}
\]

For the code to be generated by one fixed positive ordinary integer `n`, it is necessary and, within the exact parity conjugacy, equivalent to

\[
\boxed{
-c_q\longrightarrow n
\qquad\text{in }\mathbb Z_2.
}
\]

Equivalently,

\[
\boxed{
-\sum_{i=0}^{\infty}\frac{2^{A_i}}{3^{i+1}}
=n
\quad\text{in }\mathbb Z_2.
}
\]

At completed odd-event checkpoints the approximation order is exact:

\[
\boxed{v_2(n+c_q)=A_q.}
\]

## 3. Harmonic real-growth condition from no first descent

If the resulting positive-integer odd-event orbit is nonperiodic and never descends below its start, the harmonic-correction theorem gives

\[
\boxed{
c_q=O_n(q^{1/9}).}
\]

Therefore

\[
\boxed{
\sum_{i=0}^{q-1}\frac{2^{A_i}}{3^i}
=O_n(q^{1/9}).
}
\]

This single real-growth condition subsumes the earlier sparse-contracting and critical-strip consequences:

- contracting checkpoints have density zero;
- every fixed critical discrepancy strip has density zero;
- density-one event states escape above every `q^theta`, `theta<8/9`;
- recurrent contracting endpoints have polynomially small 3-adic endpoint representatives.

## 4. Consolidated nonperiodic target

### Harmonic Mixed-Place Exclusion Target

Prove that there do not exist an integer `n>=3` and an aperiodic strictly increasing integer sequence

\[
0=A_0<A_1<A_2<\cdots
\]

such that simultaneously

\[
\boxed{
-\sum_{i=0}^{\infty}\frac{2^{A_i}}{3^{i+1}}
=n
\quad\text{in }\mathbb Z_2
}
\]

and

\[
\boxed{
\sum_{i=0}^{q-1}\frac{2^{A_i}}{3^i}
=O(q^{1/9})
\quad(q\to\infty)
}
\]

hold.

A proof of this target would rule out every nonperiodic positive-integer first-descent counterexample, because every such counterexample has already been shown to satisfy both conditions.

## 5. Why this is non-enumerative

The target contains no finite cutoff in the starting integer, event depth, valuation size, or parity-word length. It is a compatibility theorem for one infinite exponent series viewed in two different completions:

\[
\boxed{
\begin{array}{ll}
\mathbb R:& \text{very slow positive partial-sum growth},\\
\mathbb Z_2:& \text{convergence to a fixed negative ordinary integer}.
\end{array}
}
\]

Thus proving it would not amount to checking longer exponent codes one at a time.

## 6. Current mathematical obstruction

The two conditions are not presently known to be contradictory by an elementary approximation theorem.

The target value `n` is rational, so standard irrational-target forms of Roth/Ridout-type approximation cannot simply be invoked. Likewise, deeper valuation congruences obtained from reset events are not independent: their pullback reproduces the next exponent-code formation bit.

Accordingly, a valid next step must exploit the **structured positive series itself**—for example a uniform lower bound on its real partial-sum growth under the assumption that its 2-adic sum is an ordinary positive integer—or derive a genuinely independent arithmetic invariant beyond the parity code.

## 7. Periodic branch remains separate

The harmonic mixed-place target assumes aperiodicity. A periodic counterexample is instead an exact boundary-lock case:

\[
C_K=n
\]

at a finite return prefix. It must be excluded by cycle-specific arithmetic/combinatorial arguments.

Thus a complete first-descent proof now has two explicit terminal tasks:

\[
\boxed{
\begin{array}{ll}
\text{Periodic:}& \text{exclude nontrivial boundary-lock cycles},\\
\text{Aperiodic:}& \text{prove harmonic mixed-place exclusion}.
\end{array}
}
\]
