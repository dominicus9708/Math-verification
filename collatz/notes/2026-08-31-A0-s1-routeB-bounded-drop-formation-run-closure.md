# A0 s=1 Route-B bounded-drop formation run closure

Date: 2026-08-31

Status: **exact formation-language structural theorem / G4 scope correction**.

This note follows the formation-cylinder theorem and corrects one unnecessary
proof obligation introduced during the semantic-renewal audit.

The formation language is existential over weakly decreasing rank paths.  It
does not require the physical Collatz orbit to deterministically choose one
rank transition at every formation depth.  Moreover, arbitrary formation depth
has bounded structural rank-change complexity.

No global Collatz conclusion is claimed.

---

## 1. Existential semantics of the established formation language

For fixed initial rank `k` and formation depth `K`, the established target
language is generated by surviving paths

\[
k=a_0\ge a_1\ge\cdots\ge a_K\ge0.
\]

For every fixed rank path the carry arithmetic determines at most one source
residue modulo `3^K`; the complete formation target language is the union over
those paths.

Therefore the correct semantic quantifier is

\[
\boxed{
\exists\,(a_0,\ldots,a_K)
\text{ weakly decreasing and formation-legal}.
}
\]

It is not necessary to define a deterministic map

\[
\text{physical orbit state}\longmapsto a_{j+1}.
\]

Accordingly the previous provisional gate

`G4-S2: deterministic formation rank-path renewal`

was stronger than the actual formation semantics and is retired.

## 2. Unique bounded-drop factorization

Let

\[
k=a_0\ge a_1\ge\cdots\ge a_K\ge0.
\]

Collect the distinct rank levels in the order encountered:

\[
b_0=k>b_1>\cdots>b_s\ge0.
\]

Let `ell_i` be the number of same-rank transitions made at level `b_i`.
Then the path factors uniquely as

\[
\boxed{
S_{b_0}^{\ell_0}
D_{b_0,b_1}
S_{b_1}^{\ell_1}
\cdots
D_{b_{s-1},b_s}
S_{b_s}^{\ell_s}
}
\]

with

\[
\ell_i\ge0,
\qquad
\sum_{i=0}^{s}\ell_i+s=K.
\]

Because each strict drop decreases a nonnegative integer rank by at least one,

\[
\boxed{s\le k.}
\]

Hence an arbitrarily long formation path starting at fixed rank `k` has at
most `k` strict structural changes and at most `k+1` same-rank runs.

This separates two notions that were previously conflated:

\[
\boxed{
\text{unbounded depth }K
\neq
\text{unbounded structural rank-word complexity}.
}
\]

## 3. Same-rank runs jump exactly

At a same-rank transition `a -> a`,

\[
d=2(2^a-2^a)=0
\]

and therefore

\[
c'={2c\over3}.
\]

After `ell` consecutive same-rank transitions,

\[
\boxed{
3^{\ell}\mid c
}
\]

is necessary and sufficient for integrality of the whole run, and then

\[
\boxed{
c_{\rm out}=2^{\ell}{c\over3^{\ell}}.}
\]

Writing

\[
c=3^{\ell}n
\]

gives the exact family jump

\[
\boxed{
3^{\ell}n\longmapsto2^{\ell}n.
}
\]

Thus the formation-cylinder summary of a same-rank run of arbitrary length is
simply

\[
\boxed{(\ell,0,0).}
\]

No individual same-rank step needs to be materialized.

## 4. Sparse-drop unrolling

For the general formation recurrence

\[
c_{j+1}
=
{2c_j+d_j\over3},
\qquad
 d_j=2(2^{a_j}-2^{a_{j+1}}),
\]

iterating `K` steps gives the exact identity

\[
\boxed{
3^Kc_K
=
2^Kc_0+
\sum_{j=0}^{K-1}2^{K-1-j}3^j d_j.
}
\]

Define

\[
D(a_\bullet)
:=
\sum_{j=0}^{K-1}2^{K-1-j}3^j d_j.
\]

Every same-rank step has `d_j=0`.  Therefore `D` has one nonzero term only at a
strict rank drop.

If the strict drops occur at transition positions

\[
p_1<\cdots<p_s
\]

with levels

\[
b_{i-1}\to b_i,
\]

then

\[
\boxed{
D
=
\sum_{i=1}^{s}
2^{K-p_i}3^{p_i}
\left(2^{b_{i-1}}-2^{b_i}\right).
}
\]

Since `s<=k`, an arbitrary-depth correction contains at most `k` nonzero drop
terms.

## 5. Direct source-cylinder formula

The final carry is integral exactly when

\[
2^Kc_0+D\equiv0\pmod{3^K}.
\]

Because `2^K` is invertible modulo `3^K`, there is exactly one source residue

\[
\boxed{
\rho
\equiv
-2^{-K}D
\pmod{3^K}.
}
\]

Choose `0<=rho<3^K` and define

\[
\boxed{
\gamma
={2^K\rho+D\over3^K}.
}
\]

Then the complete formation cylinder is

\[
\boxed{
 c_0=\rho+3^Kn
\quad\Longrightarrow\quad
 c_K=\gamma+2^Kn.
}
\]

This agrees exactly with the previously proved digit-by-digit Formation
Cylinder Theorem, but it computes the same state from the sparse drop data.

### Prefix-integrality audit

The final divisibility condition is not merely endpoint compatibility.
For a prefix of length `j`, write its unrolled numerator as

\[
N_j=2^jc_0+D_j.
\]

The full numerator satisfies

\[
N_K
\equiv
2^{K-j}N_j
\pmod{3^j},
\]

because every contribution from a later transition contains `3^j`.
Therefore

\[
3^K\mid N_K
\Longrightarrow
3^j\mid N_j
\]

for every `j`, since 2 is invertible modulo powers of 3.

Thus the direct `rho mod 3^K` formula really encodes all intermediate
integrality conditions for that fixed rank path.

## 6. Finite skeleton types and exact path count

For exactly `s` strict drops:

- choose the `s` lower rank levels from the `k` levels below the initial rank:

\[
\binom{k}{s};
\]

- distribute `K-s` same-rank transitions among the `s+1` runs:

\[
\binom{K}{s}.
\]

Hence

\[
\boxed{
\#\{\text{paths with }s\text{ drops}\}
=
\binom{k}{s}\binom{K}{s}.
}
\]

Summing gives

\[
\boxed{
\sum_{s=0}^{\min(k,K)}
\binom{k}{s}\binom{K}{s}
=
\binom{K+k}{k},
}
\]

recovering the established formation-path cardinality exactly.

But the rank-level skeletons themselves do not grow with `K`:

\[
\boxed{
\sum_{s=0}^{k}\binom{k}{s}=2^k.
}
\]

All depth dependence after choosing one of these finitely many skeleton types
is carried by the integer run-length parameters.

## 7. Consequence for the G4 proof architecture

The formation side no longer requires an arbitrary-length rank-word decoder.
It can be represented as

\[
\boxed{
\text{finite strict-drop skeleton}
+
\text{run-length parameters}
+
\text{exact formation cylinder}.
}
\]

For fixed initial rank `k`, structural rank-change depth is bounded by `k`
regardless of formation observation depth `K`.

The remaining problem is therefore not

> “which rank does the deterministic orbit select at the next one of K steps?”

but rather

> “how does the physical/variable target intersect the finite skeleton families
> as the run lengths and observation depth vary?”

This is a substantially narrower question.

## 8. Well-founded structural rank

Strict formation changes have an immediate well-founded rank:

\[
\boxed{R_{\rm form}=a.}
\]

Every strict structural drop satisfies

\[
a_{\rm new}<a_{\rm old}.
\]

Therefore there can be no infinite sequence of strict formation refinements.
The only possible unbounded-depth behavior is an increasingly long same-rank
run, which is already handled by the exact jump

\[
3^{\ell}n\mapsto2^{\ell}n.
\]

This provides the missing descent mechanism specifically for the formation
rank axis.  It does **not** establish a well-founded rank for every other
Route-B semantic gate.

## 9. Infinite same-rank tail corollary

For one fixed integer carry `c!=0`, a same-rank run can have length at most

\[
\boxed{v_3(c)}.
\]

If a fixed integer carry supports same-rank continuation for every length
`ell`, then

\[
3^{\ell}\mid c
\quad\text{for all }\ell,
\]

so necessarily

\[
\boxed{c=0.}
\]

Consequently every infinite legal formation path at fixed initial rank has
only finitely many strict drops and, after its final drop, must eventually lie
on a zero-carry same-rank tail.  This is consistent with and structurally
explains the earlier zero-carry-attractor theorem.

It does not by itself solve the variable-cut Collatz bridge, because the
formation target supplied by the physical problem changes with the cut.
