# Collatz structural verification status — 2026-08-09

## Scope

Accelerated map

\[
T(n)=\begin{cases}
n/2,&n\text{ even},\\
(3n+1)/2,&n\text{ odd}.
\end{cases}
\]

The current proof split is:

1. **Finite coefficient crossing (FCS/CST branch):** if the multiplicative coefficient first becomes <1, prove the actual iterate is already below the start.
2. **Infinite coefficient survival branch:** exclude positive integers whose parity prefix never crosses the coefficient boundary.

This note concerns branch 1.

## External structure used

Mike Winkler, arXiv:1709.03385v8 (2026-07-28):

- coefficient stopping time \(\sigma^*(x)\);
- admissible odd-position vectors \(\mathcal A_n\);
- parity/residue bijection modulo \(2^L\);
- complete rooted-tree construction under deletion of the last odd position;
- Pascal-type counting recursion;
- arithmetic transition rules between neighboring children.

These results are finite coefficient-stopping-time structure only; Winkler explicitly does not claim global Collatz convergence or equality of coefficient/classical stopping time.

## Current conjecture/target

For a fixed first coefficient-stopping length \(J\), let a prefix subtree consist of all admissible first-crossing parity words extending that prefix. For a leaf \(w\), let

\[
r(w)=\text{canonical starting residue},\qquad
z(w)=r(w)-T^J(r(w)).
\]

**Hierarchical Extremal Principle (HEP) — CONJECTURE/TARGET**

For every admissible prefix subtree,

\[
\arg\min r(w)=\arg\min z(w).
\]

If HEP holds for all first-crossing levels, then it reduces the search for a non-descent class recursively to one extremal representative per subtree.

## Matrix / higher-order formulation

At Winkler level \(n\), put

\[
q=n+1,\quad M=2^{\sigma_n},\quad P=3^q,\quad D=M-P>0.
\]

For an admissible odd-position vector

\[
\alpha=(\alpha_1,\ldots,\alpha_q),
\]

define the correction sum

\[
R(\alpha)=\sum_{i=1}^{q}3^{q-i}2^{\alpha_i}.
\]

The canonical pair \((x,y)\) satisfies

\[
My=Px+R,
\]

and the descent margin \(z=x-y\) satisfies

\[
Dx-Mz=R.
\]

The admissibility bounds are

\[
0=\alpha_1<\cdots<\alpha_q,\qquad
\alpha_{i+1}\le \kappa(i)=\lfloor i\log_2 3\rfloor.
\]

Introduce slack states

\[
s_i=\kappa(i-1)-\alpha_i.
\]

Since \(\kappa(i)-\kappa(i-1)\in\{1,2\}\), allowed slack transitions obey

\[
s_{i+1}\le s_i+\bigl(\kappa(i)-\kappa(i-1)\bigr)-1.
\]

Thus the admissible set is generated by a product of sparse lower-triangular transition matrices. A weighted transfer operator can attach the additive weight

\[
w_i(s_i)=3^{q-i}2^{\kappa(i-1)-s_i}
\]

to each state, so that the full correction sum is generated by matrix multiplication over a suitable semiring/group algebra rather than by flat enumeration.

This is the next computational direction.

## Failed route recorded

A sieve using only small factors of

\[
D=2^{\sigma_n}-3^{n+1}
\]

and reachable correction residues modulo those factors works at small levels but rapidly saturates: by roughly \(n\approx16\)–20, most small moduli have all residues reachable. Therefore a plain low-modulus transfer matrix is not expected to prove FCS globally.

The next matrix should preserve at least:

- slack state / admissibility position;
- correction residue or interval;
- canonical-start carry information;
- descent-margin extremum.

A Boolean residue matrix alone loses too much structure.
