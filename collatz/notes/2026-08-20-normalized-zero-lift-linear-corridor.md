# Normalized zero-lift linear corridor

Date: 2026-08-20

Status: **exact normalized cocycle and linear-corridor bound for zero-lift macro tails.** This is not a coefficient-stopping theorem and not a proof of the Collatz conjecture.

## 1. Macro affine data

For a length-\(B\) parity word \(W\) with \(Q\) odd steps, write

\[
T^B(x)=\frac{3^Qx+R_W}{2^B}.
\]

At an actual sparse-tail prefix of length \(s\), use

\[
a=b_s+h
\]

and the affine progression

\[
x=\rho+3^a t.
\]

Let the next macro lift digit be \(J\in\{0,\ldots,2^B-1\}\). The minimal compatible seed is

\[
x_0=\rho+3^aJ,
\]

and its new progression base is

\[
\rho'=T^B(x_0).
\]

## 2. Two normalized coordinates

Define

\[
 u:=\frac{\rho}{3^a}
\]

and

\[
\boxed{
 v:=2^s u=\frac{2^s\rho}{3^a}.
}
\]

The first normalization removes the growing ternary exponent. The second also removes the dyadic depth.

Substituting the affine block gives the exact recurrence

\[
\boxed{
 u'
 =\frac{
 u+J+R_W/3^{a+Q}
 }{2^B}.
}
\]

Since \(s'=s+B\), multiplying by \(2^{s+B}\) yields

\[
\boxed{
 v'
 =v+2^sJ+rac{2^sR_W}{3^{a+Q}}.
}
\]

Thus all multiplicative \(3^Q/2^B\) growth has disappeared from the normalized coordinate.

## 3. Sharp absolute correction bound for one block

Let the odd positions of \(W\) be

\[
0\le j_1<\cdots<j_Q\le B-1.
\]

The usual affine correction satisfies

\[
\frac{R_W}{3^Q}
 =\sum_{m=1}^{Q}\frac{2^{j_m}}{3^m}.
\]

For fixed \(Q\), the right side is maximized by placing the odd positions as late as possible:

\[
j_m=B-Q+m-1.
\]

Hence

\[
\frac{R_W}{3^Q}
\le
2^{B-Q}\left(1-\left(\frac23\right)^Q\right).
\]

For \(Q=1\), this is exactly

\[
\frac{2^{B-1}}3.
\]

For \(Q\ge2\), the expression is strictly smaller. Therefore

\[
\boxed{
0\le\frac{R_W}{3^Q}\le\frac{2^{B-1}}3.
}
\]

Equality occurs uniquely for the word

\[
0^{B-1}1.
\]

The certificate exhaustively verifies this sharp bound for every binary word through \(B=10\).

## 4. Zero-lift blocks have uniformly bounded normalized increment

For an actual coefficient-surviving state,

\[
a=b_s+h
\]

with \(h\ge0\), so

\[
3^a\ge3^{b_s}\ge2^s.
\]

If the next macro lift digit is zero, \(J=0\), then

\[
 v'-v
 =\frac{2^s}{3^a}\frac{R_W}{3^Q}.
\]

Consequently

\[
\boxed{
0\le v'-v\le\frac{2^{B-1}}3.
}
\]

This bound is independent of

- the phase \(s\),
- the surplus \(h\),
- the odd count \(Q\),
- and the current integer base \(\rho\).

For the current five-step renormalization,

\[
\boxed{
0\le v'-v\le\frac{16}{3}.
}
\]

## 5. Linear corridor for a zero-lift run

Suppose \(n\) consecutive macro blocks have \(J_i=0\). Iterating the preceding inequality gives

\[
\boxed{
 v_n
 \le
 v_0+n\frac{2^{B-1}}3.
}
\]

Since

\[
\rho_n
 =\frac{3^{a_n}}{2^{s_n}}v_n,
\]

we obtain the exact reachable-base corridor

\[
\boxed{
\rho_n
\le
\frac{3^{a_n}}{2^{s_n}}
\left(
 v_0+n\frac{2^{B-1}}3
\right).
}
\]

For \(B=5\),

\[
\boxed{
\frac{2^{s_n}\rho_n}{3^{a_n}}
\le
v_0+\frac{16}{3}n.
}
\]

This is much thinner than the a priori normalized box

\[
0<\rho_n<3^{a_n}.
\]

The full box has normalized width \(2^{s_n}\), whereas a zero-lift tail reachable from a fixed state is confined to a corridor whose normalized width grows only linearly in the number of macro blocks.

## 6. Normalized minimal-survivor criterion

Define the normalized generalized minimal survivor

\[
\boxed{
\widehat\mu_{s,h}(L)
:=
\frac{2^s}{3^{b_s+h}}\mu_{s,h}(L).
}
\]

At the \(n\)-th state of a zero-lift run, any further coefficient-surviving zero tail of length \(L\) requires

\[
\mu_{s_n,h_n}(L)\le\rho_n.
\]

Therefore the linear corridor gives the sufficient late-lift criterion

\[
\boxed{
\widehat\mu_{s_n,h_n}(L)
>
v_0+n\frac{2^{B-1}}3
\quad\Longrightarrow\quad
\text{the zero-lift tail must break within }L\text{ steps.}
}
\]

For \(B=5\), it is enough to beat

\[
v_0+\frac{16}{3}n.
\]

This is substantially sharper than asking the unnormalized minimum to reach the entire box ceiling \(3^{b_s+h}\).

## 7. Revised sparse-tail theorem target

The previous box formulation asked whether

\[
\mu_{s,h}(L)
\]

can eventually exceed every normalized base below \(3^{b_s+h}\). The new cocycle shows that a tail reachable without further lifts occupies only a linear normalized corridor.

Thus a sufficient quantitative theorem is now:

> **Normalized minimal-survivor growth.** Along coefficient-surviving phase-height states, the normalized minimum \(\widehat\mu_{s,h}(L)\) eventually exceeds every linear zero-lift corridor generated by the exact macro cocycle.

One possible strong form would be a uniform superlinear lower bound in an appropriate horizon, but no such asymptotic theorem is claimed here.

The gain is structural: the deterministic sparse-tail problem no longer needs to defeat an exponentially wide ternary box. It needs to defeat a linearly widening normalized corridor.

The cancellation of the multiplicative coefficient in \(v\) parallels the earlier Stage-3 height-credit phase-cocycle normalization: a potentially exponential multiplicative effect becomes an additive correction process after the correct coordinate change.

Here the additive increment is even explicit and nonnegative on zero-lift blocks:

\[

\]

This gives an Archimedean/min-plus counterpart to the existing Hensel/renewal additive-credit picture.
