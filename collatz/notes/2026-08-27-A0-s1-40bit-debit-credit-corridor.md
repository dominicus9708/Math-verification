## 2. Prefix debit is below 40 bits

For `s=1`,

\[

\qquad

Writing the prefix affine map as

\[

\[

The lower estimate uses only `X>2^71`, the positive coefficient deficit, and the already-certified coarse prefix-correction upper bound. The upper estimate uses only the reset input strip and `1-e^{-x}<x`.

## 5. New direct-intersection formulation

Let

\[
\mathcal L_-(X)
\]

be the set of prefix debit values generated by admissible nonnegative ballot bridges `X -> Z`, and let

\[
\mathcal L_+(Y)
\]

be the tail-credit set generated by admissible first-passage bridges `Z -> Y`.

Then the hard `s=1` branch requires

\[
\boxed{
L_+\in\mathcal L_+(Y),
\quad
L_-\in\mathcal L_-(X),
\quad
L_+-L_-=3(Y-X).

\]

Equivalently,

\[
\boxed{

\cap
\bigl(\mathcal L_-(X)+3(Y-X)\bigr)
\ne\varnothing.
}
\]

This reduces the previous 73-bit checkpoint-address intersection to a near match of two `<40`-bit ordinary digital sets.
