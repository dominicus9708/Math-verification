# Gate S: harmonic good-scale and multiplicative-block criterion

Date: 2026-09-06

Status: **SAFE CONDITIONAL LEMMA + OPEN SELECTOR ESTIMATE.**

The previous Gate-S reduction showed that uniform selector flatness is unnecessary.  This note turns that observation into a block criterion suitable for finite-state, convolution, or spectral estimates.

The key point is that the Beatty one-child loss is weighted by `1/L`.  Therefore the natural notion of “enough good scales” is **harmonic abundance**, not ordinary counting density.

---

## 1. Exact positive-margin form

At a Beatty rise `L`, let

\[
\rho_L
=
\frac{h_{\min}(L)}{h_{\max}(L)}.
\]

The cumulative bridge gives normalized loss at least

\[
\frac{3\rho_L-1}{10L}
\]

whenever `rho_L>1/3`.

Define the positive selector margin

\[
\boxed{
m_L:=(3\rho_L-1)_+.
}
\]

Then, using only non-expansion at scales where no certified positive loss is available,

\[
\boxed{
\mu_{N+1}
\le
\mu_1
\prod_{\substack{L\le N\\L\text{ rise}}}
\left(1-\frac{m_L}{10L}\right)
}
\]

provided Gate F identifies the same normalized candidate fibre at successive scales.

Since `1-x<=exp(-x)`,

\[
\boxed{
\mu_{N+1}
\le
\mu_1
\exp\left(
-\frac1{10}
\sum_{\substack{L\le N\\L\text{ rise}}}
\frac{m_L}{L}
\right).
}
\]

Therefore the weakest direct Gate-S target generated by this route is

\[
\boxed{
\sum_{L\text{ rise}}
\frac{(3\rho_L-1)_+}{L}
=+\infty.
}
\]

Status: **SAFE CONDITIONAL LEMMA.**

No pointwise lower bound on `rho_L` is required.

---

## 2. Fixed-margin good-rise criterion

Fix any

\[
\eta>0
\]

and define

\[
G_\eta
:=
\left\{
L:\ L\text{ is a rise and }
\rho_L\ge\frac13+\eta
\right\}.
\]

On `G_eta`,

\[
3\rho_L-1\ge3\eta.
\]

Hence

\[
\boxed{
\mu_{N+1}
\le
\mu_1
\exp\left(
-\frac{3\eta}{10}
\sum_{\substack{L\le N\\L\in G_\eta}}
\frac1L
\right).
}
\]

Consequently,

\[
\boxed{
\sum_{L\in G_\eta}\frac1L=\infty
\quad\Longrightarrow\quad
\mu_N\to0.
}
\]

This is strictly weaker than requiring all sufficiently large rises to satisfy the same margin.

Status: **SAFE CONDITIONAL LEMMA.**

---

## 3. Harmonic-density corollary

Suppose there are constants

\[
\eta>0,
\qquad
\beta>0,
\qquad
C<\infty
\]

such that

\[
\sum_{\substack{L\le N\\L\in G_\eta}}
\frac1L
\ge
\beta\log N-C
\]

for all sufficiently large `N`.

Then

\[
\boxed{
\mu_N
\le
C' N^{-3\eta\beta/10}.
}
\]

Thus any positive harmonic density of rises with a fixed selector margin gives an explicit polynomial candidate-mass decay exponent.

Status: **SAFE CONDITIONAL COROLLARY.**

---

## 4. Multiplicative-block criterion

Fix

\[
\lambda>1.
\]

Consider multiplicative blocks

\[
B_j
=
[\lambda^j,\lambda^{j+1})\cap\mathbb N.
\]

Assume there are constants

\[
\eta>0,
\qquad
\delta>0
\]

such that for every sufficiently large `j`,

\[
\boxed{
\sum_{L\in G_\eta\cap B_j}
\frac1L
\ge\delta.
}
\]

The number of completed blocks below `N` is

\[
\frac{\log N}{\log\lambda}+O(1).
\]

Therefore

\[
\sum_{\substack{L\le N\\L\in G_\eta}}
\frac1L
\ge
\frac{\delta}{\log\lambda}\log N-O(1),
\]

and hence

\[
\boxed{
\mu_N
\le
C(\lambda,\eta,\delta)
N^{-\frac{3\eta\delta}{10\log\lambda}}.
}
\]

Status: **SAFE CONDITIONAL LEMMA.**

This formulation is useful because a proof may establish one nontrivial amount of good selector mass per multiplicative scale block without controlling every `L`.

---

## 5. Counting version inside a block

A still more concrete sufficient condition follows from

\[
L<\lambda X
\quad\Longrightarrow\quad
\frac1L>\frac1{\lambda X}
\]

for `L in [X,lambda X)`.

If every sufficiently large block `[X,lambda X)` contains at least

\[
cX
\]

good rises from `G_eta`, for some `c>0`, then

\[
\sum_{L\in G_\eta\cap[X,\lambda X)}\frac1L
\ge
\frac{cX}{\lambda X}
=
\frac c\lambda.
\]

Thus the block criterion holds with

\[
\delta=\frac c\lambda.
\]

This gives

\[
\boxed{
\mu_N
\le
C N^{-\frac{3\eta c}{10\lambda\log\lambda}}.
}
\]

Status: **SAFE CONDITIONAL COROLLARY.**

Ordinary positive density of good rises in every multiplicative block is therefore more than enough, but is not necessary.

---

## 6. Discrepancy version

Using the one-sided selector discrepancies

\[
h_L(x)\ge(1-d_L)\bar h_L,
\qquad
h_L(x)\le(1+u_L)\bar h_L,
\]

the earlier reduction gives

\[
3\rho_L-1
\ge
\frac{2-3d_L-u_L}{1+u_L}.
\]

Hence the exact harmonic target may be weakened to

\[
\boxed{
\sum_{L\text{ rise}}
\frac{(2-3d_L-u_L)_+}{(1+u_L)L}
=+\infty.
}
\]

For symmetric discrepancy `epsilon_L`, it is enough that

\[
\boxed{
\sum_{L\text{ rise}}
\frac{(1-2\varepsilon_L)_+}{(1+\varepsilon_L)L}
=+\infty.
}
\]

The block criterion can be applied to either margin rather than directly to `rho_L`.

---

## 7. Fourier-tail version

For

\[
\Theta_L
=
\frac{\sum_{t\ne0}|\widehat h_L(t)|}
{\widehat h_L(0)},
\]

we have

\[
\varepsilon_L\le\Theta_L.
\]

Thus define, for a fixed `tau<1/2`,

\[
G_\tau^{\rm F}
:=
\{L:\ L\text{ rise and }\Theta_L\le\tau\}.
\]

On this set,

\[
\kappa_L
\ge
\frac{1-2\tau}{5(1+\tau)}.
\]

Therefore any multiplicative-block theorem of the form

\[
\sum_{L\in G_\tau^{\rm F}\cap B_j}\frac1L
\ge\delta>0
\]

implies polynomial candidate-mass decay.

This is a much weaker spectral target than a uniform theorem `Theta_L<=tau` for every sufficiently large `L`.

Status: **SAFE CONDITIONAL FOURIER REDUCTION.**

---

## 8. Why this matters computationally

Finite H24/H25 min/max data already show selector ratios far above `1/3`, but finite data cannot prove a pointwise asymptotic lower bound.

The block criterion changes what future computation should test.

Instead of asking only

\[
\min_{L\le L_{\max}}\rho_L>\frac13\ ?
\]

one should record, by multiplicative scale block:

1. number of Beatty rises;
2. number of rises with `rho_L>=1/3+eta` for several fixed `eta`;
3. harmonic weight
   \[
   \sum 1/L
   \]
   of those good rises;
4. corresponding accumulated certified contraction exponent.

A small number of bad scales is irrelevant if the good-scale harmonic mass remains non-summable.

## 9. DSD audit

### SAFE

1. The natural cumulative Gate-S quantity is
   \[
   \sum_{L\text{ rise}}(3\rho_L-1)_+/L.
   \]
2. Divergence of that sum implies candidate-mass decay under Gate-F compatibility and normalized non-expansion.
3. A fixed-margin subset with divergent harmonic sum suffices.
4. A positive harmonic contribution in every multiplicative block suffices.
5. Pointwise selector flatness at every large scale is unnecessary.

### OPEN

- Prove any one of these harmonic/block conditions for the **exact** selector multiplicity.

### PROHIBITED UPGRADES

1. Do not infer block abundance from a finite initial range.
2. Do not replace harmonic abundance by ordinary density without checking the weighting.
3. Do not apply the criterion before `F_map` establishes that `rho_L` belongs to the exact canonical candidate fibre.
4. Candidate-mass decay still does not close terminal Gate C.

## 10. Revised Gate-S target

The strongest old target was

\[
\inf_L\rho_L>\frac13.
\]

The current weakest direct target is

\[
\boxed{
\sum_{L\text{ rise}}
\frac{(3\rho_L-1)_+}{L}=\infty.
}
\]

For proof construction, a practical intermediate target is the multiplicative-block statement

\[
\boxed{
\exists\eta,\delta>0,\ \lambda>1:
\quad
\sum_{L\in G_\eta\cap[\lambda^j,\lambda^{j+1})}
\frac1L\ge\delta
}
\]

for all sufficiently large `j`.

This is the next preferred Gate-S theorem to seek if a pointwise min/max estimate remains too strong.
