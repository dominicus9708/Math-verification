## 1. Setup

Use the accelerated map

\[
T(n)=\begin{cases}
n/2,&n\text{ even},\\
(3n+1)/2,&n\text{ odd}.
\end{cases}
\]

Let

\[
a_j:=\min\{q:3^q\ge 2^j\}=\lceil j\log_3 2\rceil.
\]

At depth `k`, let a coefficient-surviving canonical state be

\[
(k,q;r,y),
\]

and fix a target depth

\[
K=k+m.
\]

Write

\[
\eta:=y\bmod 2^m,
\qquad
s:=q-a_k\ge0.
\]

For a future endpoint integer `x`, let `Q_j(x)` denote the number of odd entries among the first `j` accelerated steps of the orbit of `x`.

## 2. Future-admissibility kernel

Define

\[
\boxed{
B_{k,q,m}:=
\left\{
x\bmod 2^m:
q+Q_j(x)\ge a_{k+j}
\text{ for every }1\le j\le m
\right\}.
}
\]

This is the set of endpoint residues whose next `m` parity steps keep the total coefficient above the contraction barrier.

Every length-`m` canonical extension of the current prefix has the form

\[
r'=r+2^k u,
\qquad 0\le u<2^m.
\]

Because the first `k` parity bits are unchanged by adding `2^k u`, the affine parity formula gives

\[
\boxed{
T^k(r+2^k u)=y+3^q u.
}
\]

Therefore the extension survives to depth `K` iff

\[
\eta+3^q u\pmod{2^m}\in B_{k,q,m}.
\]

Since `3^q` is odd, multiplication by `3^q` is a permutation modulo `2^m`. Hence the exact future value function is

\[
\boxed{
J_{k,K}(q,\eta)
=
\min\left\{
u\in[0,2^m):
\eta+3^q\nu\pmod{2^m}\in B_{k,q,m}
\right\}.
}
\]

The least depth-`K` canonical descendant of the state is therefore

\[
\boxed{
r+2^k J_{k,K}(q,\eta).
}
\]

This is an exact modular first-hit formulation of the finite-horizon min-plus problem.

\[

The current lift bit is `c`, so the relative extension integer decomposes as

## 4. Slack form of the future barrier

Because

\[
q=a_k+s,
\]

the future condition becomes

\[
\boxed{
s+Q_j(x)\ge a_{k+j}-a_k.}
\]

Thus `q` enters the barrier only through the slack `s`.

Define the threshold-increment word

\[
\delta_j:=a_{j+1}-a_j\in\{0,1\}.
\]

Then

\[
a_{k+j}-a_k=\sum_{t=0}^{j-1}\delta_{k+t}.
\]

Hence the kernel depends on absolute depth `k` only through the finite mechanical factor

\[
\boxed{(\delta_k,\ldots,\delta_{k+m-1})}
\]

and on the state only through the slack `s`.

## 5. Sturmian factor reduction

Let

\[
\alpha=\log_3 2.
\]

Since `alpha` is irrational,

\[
\delta_j=\lceil (j+1)\alpha\rceil-\lceil j\alpha\rceil
\]

is an upper mechanical (Sturmian) binary word.

For a fixed horizon length `m`, a length-`m` factor changes only when the rotation phase `{k alpha}` crosses one of the `m` cut points generated by the threshold boundaries. These cut points partition the circle into at most `m+1` intervals. Therefore

\[
\boxed{
\#\left\{
(\delta_k,\ldots,\delta_{k+m-1}):k\ge0
\right\}
\le m+1.
}
\]

For an irrational mechanical word the factors are in fact distinct, giving the classical Sturmian complexity `m+1`; only the upper bound is needed here.

Thus, for fixed `(m,s)`, the infinitely many absolute depths `k` produce at most `m+1` distinct future coefficient-barrier kernels before the arithmetic translation/multiplication by `(eta,3^q)` is applied.

distinct length-`m` factors, respectively.

## 6. High-slack saturation

Let

\[
A_{k,m}:=a_{k+m}-a_k.
\]

If

\[
\boxed{s\ge A_{k,m},}
\]

then for every `1<=j<=m`,

\[
a_{k+j}-a_k\le A_{k,m}\le s,
\]

while `Q_j(x)>=0`. Hence every future endpoint residue is coefficient-admissible:

\[
\boxed{B_{k,q,m}=\mathbb Z/2^m\mathbb Z.}
\]

Consequently

\[
\boxed{J_{k,K}(q,\eta)=0}
\]

for every endpoint residue `eta` in this high-slack regime. The canonical state already survives to `K` without any further start lift.

This yields an exact dominance rule for a fixed target: once a best depth-`K` start `R_best` is known, every high-slack state with `r>=R_best` can be pruned immediately.

## 7. Exact zero-lift certificate below saturation

The high-slack condition is sufficient but not necessary. For any state, let the actual no-lift endpoint orbit start at `eta` and let `Q_j(eta)` be its prefix odd counts. Then

\[
\boxed{
J_{k,K}(q,\eta)=0
\iff
s+Q_j(\eta)\ge a_{k+j}-a_k
\quad(1\le j\le m).
}
\]

Thus zero additional lift can be certified by a single `m`-step parity scan of the endpoint residue, without exploring alternative suffixes.
