# Whole-prefix maximality is an endpoint min-plus transition

Date: 2026-08-24

Status: **exact algebraic reformulation.**  This replaces complete correction-class rescanning by a one-step comparison against one opposite-parity endpoint fibre once the previous prefix is already maximal.  It is not a proof of the Collatz conjecture.

## 1. Endpoint fibre minimum

For the accelerated Collatz map define

\[
\mu_{h,q}(y)
:=\min\{n>0:T^h(n)=y,\ q_h(n)=q\},
\]

with \(+\infty\) when the fibre is empty.

If a length-h parity word has correction R, q odd steps, root n and endpoint y, then

\[
2^h y=3^q n+R.
\]

For two roots in the same fixed \((h,q,y)\) fibre,

\[
R_2-R_1=3^q(n_1-n_2).
\]

Hence larger correction is exactly smaller root.  Therefore

\[
\boxed{
\text{whole-prefix maximum correction}
\iff
n=\mu_{h,q}(y).
}
\]

This is the endpoint form of the unconditional whole-prefix predecessor theorem.

## 2. Exact one-step min-plus recurrence

Every h-step preimage of y ends in exactly one of two reverse branches.

The even last step has pre-final endpoint

\[
x_E=2y
\]

and does not change q.

The odd last step exists exactly when

\[
y\equiv2\pmod3,
\]

in which case

\[
x_O=\frac{2y-1}{3}
\]

is automatically odd and consumes one odd step.

Thus

\[
\boxed{
\mu_{h,q}(y)
=
\min\left(
\mu_{h-1,q}(2y),
\mu_{h-1,q-1}\!\left(\frac{2y-1}{3}\right)
\right),
}
\]

with the second term omitted when \(y\not\equiv2\pmod3\).

This is an exact min-plus recurrence, not a probabilistic approximation.

## 3. Once the previous prefix is maximal, only one sibling fibre matters

Suppose the actual root N is already maximum-correction / minimum-root at depth h-1.

Let its pre-final endpoint be x.

### Actual last bit even

Then x is even and the new endpoint is

\[
y=x/2.
\]

The even branch of the min-plus recurrence already has minimum root N.  A loss of maximality can therefore occur only through the opposite odd branch.  That branch exists exactly when

\[
x\equiv1\pmod3,
\]

and its pre-final endpoint is

\[
\boxed{x_O=\frac{x-1}{3}.}
\]

Thus the new prefix remains maximal iff

\[
N\le\mu_{h-1,q-1}\!\left(\frac{x-1}{3}\right).
\]

### Actual last bit odd

Now x is odd and

\[
y=\frac{3x+1}{2}.
\]

The odd branch already has minimum root N.  The only possible competitor is the opposite even branch, whose pre-final endpoint is

\[
\boxed{x_E=2y=3x+1.}
\]

If the new total odd count is q, the prefix remains maximal iff

\[
N\le\mu_{h-1,q}(3x+1).
\]

Therefore

\[
\boxed{
\text{first loss of whole-prefix maximality}
\text{ is necessarily a mixed-q last-step exchange.}
}
\]

No same-last-bit competitor can be the first failure: it would already contradict maximality one step earlier.

## 4. Relation to terminal propagation

The previous terminal-propagation theorem showed that once a root is non-maximal, appending its actual suffix preserves the same positive root credit.  Hence non-maximality is forward absorbing.

The present recurrence supplies the complementary local statement:

- while maximality holds, the next test has only one opposite-parity competitor fibre;
- after the first failure, no later maximality test can recover.

So whole-prefix maximality along a fixed orbit has the structure

\[
\boxed{
1,1,\ldots,1,0,0,\ldots
}
\]

with at most one transition from maximal to non-maximal.

## 5. Consequence for the m=45 depth-200 problem

The finite terminal set

\[
\mathcal C_{45}\cap\mathcal S_{200}\cap\mathcal M_{200}
\]

need not be constructed by enumerating every complete Hensel correction class at H=200.

For any concrete candidate, one may instead propagate its actual orbit and maintain the invariant

\[
N=\mu_{h,q_h}(T^h(N)).
\]

At each step, only the opposite-parity sibling endpoint minimum must be compared with N.

The remaining difficulty is therefore sharply localized:

> efficiently lower-bound or compute the single sibling-fibre minimum \(\mu_{h-1,q'}(y')\) for the endpoints generated by the m=45 selector family.

This is an endpoint-transfer/min-plus problem.  It is smaller conceptually than rescanning all correction words, but it is not yet solved uniformly.
