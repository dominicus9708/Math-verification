# A0 s=1 Route-B — source-channel projective quotient

Date: 2026-08-31  
Branch: `collatz-stage4-window-threshold`

## 1. Problem

The family-cover ballot/correction quotient can safely reuse A/B certificates that depend only on its observable state, but unresolved C-refinement still acts on the exact affine source channel

\[
X=r+2^hm,
\qquad
T^h(X)=y+3^qm.
\]

The next question is whether future source refinement really needs the complete integers \(y,q\).

## 2. Finite-horizon quotient

For \(d\ge1\), define

\[
\boxed{
Q_d(P)=\left(y\bmod2^d,\ 3^q\bmod2^d\right).
}
\]

Let \(B\) be a binary block of length \(\ell\le d\), with one-count \(q_B\), correction \(C_B\), and canonical source residue

\[
\rho_B\equiv-C_B(3^{q_B})^{-1}\pmod{2^\ell}.
\]

For the parent channel, the block selects

\[
\boxed{
m_B\equiv(\rho_B-y)(3^q)^{-1}\pmod{2^\ell}.}
\]

Therefore \(m_B\) depends only on \(Q_d(P)\), because reduction of \(Q_d\) modulo \(2^\ell\) gives both \(y\bmod2^\ell\) and \(3^q\bmod2^\ell\).

The child endpoint is

\[
y_B=
\frac{3^{q_B}(y+3^qm_B)+C_B}{2^\ell}.
\]

If two parent channels have the same \(Q_d\), the difference of their child numerators is divisible by \(2^d\).  Division by \(2^\ell\) therefore gives

\[
\boxed{
y_B\equiv y'_B\pmod{2^{d-\ell}}.}
\]

Also

\[
3^{q+q_B}\equiv3^{q'+q_B}\pmod{2^{d-\ell}}.
\]

Hence

\[
\boxed{
Q_d(P)=Q_d(P')
\Longrightarrow
\begin{cases}
m_B(P)=m_B(P')\pmod{2^\ell},\\
Q_{d-\ell}(P\cdot B)=Q_{d-\ell}(P'\cdot B).
\end{cases}
}
\]

This is an exact **precision-consuming right congruence** for the affine source-channel control state.

## 3. Transition-kernel consequence

The exact interval pullback for a parent payload

\[
I=[L,U]\cap\mathbb Z
\]

is

\[
\Phi_{m_B,\ell}(I)=
\left[
\left\lceil\frac{L-m_B}{2^\ell}\right\rceil,
\left\lfloor\frac{U-m_B}{2^\ell}\right\rfloor
\right]\cap\mathbb Z.
\]

Thus two \(Q_d\)-equivalent channels use the same control transition and the same pullback operator for every common block of length at most \(d\).  Their actual finite intervals may differ, so the interval remains an exact payload rather than being merged into \(Q_d\).

This gives a clean control/payload split:

\[
\boxed{
\text{control}=Q_d,
\qquad
\text{payload}=I,
\qquad
R(I)=|I|.
}
\]

The previously proved interval rank still decreases strictly under nontrivial one-bit C-refinement.

## 4. Size of the control quotient

The first coordinate has at most \(2^d\) values.  The second coordinate lies in the cyclic subgroup generated by \(3\) modulo \(2^d\).  For \(d\ge3\), that subgroup has order \(2^{d-2}\).  Hence

\[
|Q_d|\le2^{2d-2}
\qquad(d\ge3).
\]

This is finite for every requested lookahead depth and independent of the absolute channel depth \(h\), absolute source residue \(r\), and the magnitudes of \(y,q\).

## 5. Projective structure

The quotients are compatible under reduction:

\[
Q_{d+1}\longrightarrow Q_d.
\]

A block of length \(\ell\) consumes exactly \(\ell\) units of 2-adic precision:

\[
Q_d\xrightarrow{B,\ |B|=\ell}Q_{d-\ell}.
\]

Thus the natural global object is a projective 2-adic channel state, not a newly claimed horizon-independent finite automaton.

## 6. DSD audit

### Exact / closed

- \(Q_d=(y\bmod2^d,3^q\bmod2^d)\) determines every length-\(\ell\le d\) parameter residue;
- equal \(Q_d\) states remain equal at child precision \(d-\ell\);
- the same symbolic interval-pullback operator is reused for equal control states;
- finite-horizon source-channel control has an exact quotient independent of absolute channel depth.

### Regression only

`collatz/src/A0_s1_routeB_source_channel_projective_quotient_certificate.py` checks the transition identity and deliberately distinct equivalent representatives over 301,200 finite comparisons through precision 8.  These are implementation guards, not the proof.

### Still open

1. precision is consumed, so this alone does not give a horizon-independent finite state;
2. exact interval payloads are not identified merely because their control states agree;
3. a family-level A/B closure theorem must still show how large unions of interval payloads are certified without enumerating singleton leaves;
4. universal Route-B membership and the Collatz conjecture remain open.

## 7. Updated bottleneck

The affine source-channel transition itself no longer requires unbounded exact integer state at a fixed lookahead horizon.
