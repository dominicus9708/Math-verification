## 2. Four oriented positive gaps

Let \(H_h^*\) and \(L_h^*\) denote the characteristic strict-high and low
target words.

For \(W\in\mathcal H_h\), define

\[
\Delta_{HF}(W)=C(H_h^*)-C(W),
\]

\[
\Delta_{HR}(W)=C(\operatorname{rev}W)-C(\operatorname{rev}H_h^*).
\]

For \(W\in\mathcal L_h\), define

\[
\Delta_{LF}(W)=C(W)-C(L_h^*),
\]

\[
\Delta_{LR}(W)=C(\operatorname{rev}L_h^*)-C(\operatorname{rev}W).
\]

All four are nonnegative.

The sign change between H and L is not cosmetic.  H words move ranked ones to
the left of the characteristic target, whereas L words move them to the right.
Reversal exchanges the orientation again.

Thus the four quantities are the natural positive defect coordinates respected
by the dual H/L grammar.

## 3. Fixed-resolution state

Fix any positive modulus \(M\), in particular

\[
M=2^K3^L.
\]

Use the bidirectional correction observation

\[
\rho_M(W)
=
\left(
C(W)\bmod M,
C(\operatorname{rev}W)\bmod M
\right).
\]

For each H state key \(\rho\), retain only

\[
\boxed{
D_H(h,\rho)
=
\bigl(
\min\Delta_{HF},
\min\Delta_{HR}
\bigr).
}
\]

For each L state key retain

\[
\boxed{
D_L(h,\rho)
=
\bigl(
\min\Delta_{LF},
\min\Delta_{LR}
\bigr).
}
\]

The two minima need not be attained by the same word.  This is nevertheless
exact because the forward parent recurrence queries only the child's required
forward/reverse scalar minimum independently, and the reverse parent recurrence
does the analogous thing.

Therefore no two-dimensional Pareto frontier is needed.

## 4. The anchor-offset issue

A critical DSD audit point appeared here.

An arbitrary **admissible candidate grammar cut** need not equal the
characteristic target's own canonical cut.

For example, \(\mathcal H_4\) has an admissible production at \(c=1\), but its
characteristic child-product anchor is not literally \(H_4^*\).

Therefore it would be incorrect to write only

\[
\text{parent defect}
=
\text{weighted child defects}.
\]

One must first introduce the legal production anchor \(A_c\) and include

\[
\boxed{
\text{global-target/anchor offset}
+
\text{anchor/candidate child defect}.
}
\]

Because every anchor generated by the converse grammar is itself a legal H or
L word, the appropriate oriented anchor offset is nonnegative.

This prevents the candidate's canonical cut from being silently imposed on the
target.

## 5. H recurrence

For an admissible H production

\[
W=UV,
\qquad
U=1\operatorname{rev}(X),
\qquad
X\in\mathcal L_{c-1},
\qquad
V\in\mathcal H_s,
\]

let

\[
A_c
=
\left(1\operatorname{rev}L_{c-1}^*\right)H_s^*.
\]

Define the nonnegative anchor offsets

\[
A_{HF}=C(H_h^*)-C(A_c),
\]

\[
A_{HR}=C(\operatorname{rev}A_c)-C(\operatorname{rev}H_h^*).
\]

Then

\[
\boxed{
\Delta_{HF}(W)
=
A_{HF}
+2\,3^{q_H(s)}\Delta_{LR}(X)
+2^c\Delta_{HF}(V).
}
\]

The reverse orientation is

\[
\boxed{
\Delta_{HR}(W)
=
A_{HR}
+3^{q_H(c)}\Delta_{HR}(V)
+3\,2^s\Delta_{LF}(X).
}
\]

All coefficients are positive.

\left(0\operatorname{rev}H_{c-1}^*\right)L_s^*.

The positive recurrences are

\[
\boxed{
\Delta_{LF}(W)
=
A_{LF}
+2\,3^{q_L(s)}\Delta_{HR}(X)
+2^c\Delta_{LF}(V),
}
\]

and

\[
\boxed{
\Delta_{LR}(W)
=
A_{LR}
+3^{q_L(c)}\Delta_{LR}(V)
+2^s\Delta_{HF}(X).
}
\]

For the primitive \(c=1\), the absent H child contributes zero.

## 7. Why scalar minima compose exactly

Fix a parent residue key \(\rho\).

Every legal parent production determines child residue keys

\[
\rho_X,\rho_V
\]

whose bidirectional correction composition equals \(\rho\).

For the forward H recurrence, for example, the cost is

\[
A_{HF}
+2\,3^{q_H(s)}\Delta_{LR}(X)
+2^c\Delta_{HF}(V).
\]

At fixed child keys the two child choices are independent Cartesian factors.
Since both coefficients are positive, the minimum is exactly

\[
A_{HF}
+2\,3^{q_H(s)}
\min_{\rho_X}\Delta_{LR}
+2^c
\min_{\rho_V}\Delta_{HF}.
\]

The same argument applies to all four orientations.

Hence state merging by independent scalar minima is exact.

## 8. Fixed-resolution state bound

The residue key lies in

\[
(\mathbf Z/M\mathbf Z)^2.
\]

Therefore each H or L length has at most

\[
M^2
\]

keys.

There are two scalar orientations per type, so across H/L the total number of
stored scalar min-plus values at one length is at most

\[
\boxed{4M^2.}
\]

Through all integer lengths \(0\le h\le H\), the coarse bound is

\[
\boxed{4(H+1)M^2.}
\]

This is a state-count theorem at fixed observation resolution, not a claim that
iterating all \(H\) layers is acceptable for the actual billion-scale target.
