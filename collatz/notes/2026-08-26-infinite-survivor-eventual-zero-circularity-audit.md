# Infinite coefficient-survivor branch: eventual-zero lift circularity audit

Date: 2026-08-26

Status: **logical dependency audit.** This note prevents the odd-only canonical-lift naturalness criterion from being mistaken for an independent Collatz exclusion theorem.

## 1. Canonical lift recap

In the odd-only formulation let \(F_q\) be the canonical formation floor after \(q\) odd events and let \(A_q\) be the cumulative halving count. Exact canonical lifting has the form

\[
F_{q+1}=F_q+\varepsilon_q2^{A_q},
\qquad
\varepsilon_q\in\{0,1\}.
\]

For a path generated by one fixed finite positive integer \(N\), once

\[
2^{A_q}>N,
\]

the canonical residue has already exposed the entire ordinary integer, so

\[
F_q=N
\]

and hence

\[
\boxed{\varepsilon_q=0\quad\text{for all sufficiently large }q.}
\]

Conversely, infinitely many nonzero canonical lift digits force the formation floor to be unbounded and therefore cannot represent one fixed finite natural number.

## 2. What this does prove

The exact naturalness dichotomy is

\[
\boxed{
\text{fixed finite natural path}
\Longrightarrow
\varepsilon_q\text{ is eventually zero},
}
\]

while

\[
\boxed{
\varepsilon_q\ne0\text{ infinitely often}
\Longrightarrow
F_q\to\infty.
}
\]

This is useful for classifying infinite 2-adic/parity paths into finite-natural and escaping-formation branches.

## 3. What it does not prove

The statement

\[
\text{coefficient survivor} + \text{eventual-zero lift is impossible}
\]

has **not** been proved.

Indeed, after the lift digits become zero, the normalized state simply follows the ordinary odd-only Collatz recurrence. Therefore using eventual-zero alone to exclude an infinite coefficient-surviving natural orbit would merely rephrase the original problem.

Consequently the implication

\[
\boxed{
\text{eventual-zero lift}
\Longrightarrow
\text{contradiction}
}
\]

must not appear in the proof chain without an additional independent theorem.

## 4. What would constitute genuine progress

A valid closing lemma must combine eventual-zero naturalness with an independently proved survivor constraint. Examples of logically sufficient targets include:

1. **survivor-Hensel incompatibility**
   \[
   \text{coefficient survival}+
   \text{survivor-Hensel maximality}
   \Longrightarrow
   \varepsilon_q\ne0\text{ infinitely often};
   \]
2. **minimal-survivor growth**
   \[
   \mu(K):=\min\{n:\tau_c(n)>K\}\to\infty;
   \]
3. **formation-floor escape**
   every infinite coefficient-surviving branch has
   \[
   F_q\to\infty;
   \]
4. an equivalent monotone two-boundary theorem forcing
   \[
   \rho_k>\Theta_k
   \]
   at some finite depth for every bounded-floor branch.

Any one of these would add information not contained in the definition of a finite natural orbit.

## 5. DSD audit verdict

The canonical lift digit is a useful **state descriptor**, but eventual-zero is currently a **domain/naturalness descriptor**, not a contradiction channel.

Thus the correct DSD chain is

\[
\text{infinite survivor path}
\to
\begin{cases}
\varepsilon_q\ne0\text{ infinitely often}
&\Rightarrow\text{formation floor escapes},\\
\varepsilon_q=0\text{ eventually}
&\Rightarrow\text{finite-natural branch remains to be excluded independently}.
\end{cases}
\]

This separation prevents a circular proof.

## 6. Current Branch-I target

The cleanest present target remains

\[
\boxed{\mu(K)\to\infty}
\]

or an equivalent theorem showing that coefficient-surviving prefixes require unbounded canonical formation floors.

Until such a theorem is proved, Branch I remains open even if every finite first-coefficient-crossing resonance is eliminated.
