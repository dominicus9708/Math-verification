# Formation floor and survival ceiling for Collatz prefix classes

Date: 2026-08-11

Status: **exact monotone-boundary theorem**. This strengthens the earlier interval-channel description: for positive canonical parity classes, dynamic no-first-descent constraints create only upper bounds, never new lower bounds.

## 1. Affine prefix form

For a realizable accelerated Collatz parity prefix of length \(k\), let

\[
p_0,\ldots,p_{k-1}\in\{0,1\}
\]

and

\[
Q_j:=\sum_{i=0}^{j-1}p_i.
\]

There is a nonnegative integer correction \(R_j\) such that every positive integer realizing the prefix satisfies

\[
\boxed{
T^j(n)=\frac{3^{Q_j}n+R_j}{2^j},
\qquad 1\le j\le k.
}
\]

The correction recurrence is

\[
R_0=0,
\qquad
R_{j+1}=3^{p_j}R_j+p_j2^j,
\]

so

\[
\boxed{R_j\ge0.}
\]

---

## 2. One-prefix no-descent inequality

The condition

\[
T^j(n)\ge n
\]

is equivalent to

\[
\boxed{
(3^{Q_j}-2^j)n+R_j\ge0.
}
\]

For \(j\ge1\), equality \(3^{Q_j}=2^j\) is impossible.

Therefore exactly two cases occur.

### Expanding coefficient

If

\[
3^{Q_j}>2^j,
\]

then, because \(n>0\) and \(R_j\ge0\),

\[
\boxed{T^j(n)>n}
\]

for every positive integer realizing the prefix. This prefix time contributes no upper or lower restriction on the positive start.

### Contracting coefficient

If

\[
3^{Q_j}<2^j,
\]

then

\[
T^j(n)\ge n
\iff
\boxed{
n\le C_j
:=
\frac{R_j}{2^j-3^{Q_j}}.
}
\]

Thus every contracting prefix time contributes only an upper ceiling on the initial integer.

---

## 3. Survival ceiling

For a length-k parity prefix \(w\), define

\[
\boxed{
\Theta_k(w)
:=
\min_{\substack{1\le j\le k\\3^{Q_j}<2^j}}
\frac{R_j}{2^j-3^{Q_j}},
}
\]

with

\[
\Theta_k(w)=+\infty
\]

if no contracting prefix time occurs.

Then a positive integer realizing the parity prefix has no first descent through time k iff

\[
\boxed{n\le\Theta_k(w).}
\]

The ceiling is monotone along prefix extension:

\[
\boxed{
\Theta_{k+1}\le\Theta_k.
}
\]

---

## 4. Formation floor

A realizable length-k parity prefix determines one residue class modulo \(2^k\). Let

\[
\boxed{
\rho_k(w)
:=
\min\{n\ge2:n\text{ realizes }w\}.
}
\]

Then every positive start \(n\ge2\) realizing the prefix has the form

\[
\boxed{
n=\rho_k(w)+2^k m,
\qquad m\in\mathbb Z_{\ge0}.
}
\]

Along extension of one infinite parity path, the formation classes are nested, so

\[
\boxed{
\rho_{k+1}\ge\rho_k.
}
\]

For a path generated by a finite positive integer \(n\), \(\rho_k\) eventually stabilizes at \(n\) once the modulus exceeds the binary size of \(n\).

---

## 5. Exact survivor cylinder theorem

Combining formation and dynamics, the unresolved starts in the prefix class are exactly

\[
\boxed{
S_k(w)
=
\left\{
\rho_k(w)+2^k m:
0\le m,
\ \rho_k(w)+2^k m\le\Theta_k(w)
\right\}.
}
\]

Therefore the lift-coordinate survivor set is never a dynamically generated interval with positive lower endpoint. It is always

\[
\boxed{[0,U_k(w)]\cap\mathbb Z}
\]

or

\[
\boxed{[0,+\infty)\cap\mathbb Z.}
\]

If \(\Theta_k<\infty\),

\[
\boxed{
U_k(w)
=
\left\lfloor
\frac{\Theta_k(w)-\rho_k(w)}{2^k}
\right\rfloor
}
\]

provided \(\rho_k\le\Theta_k\); otherwise the class is empty.

Thus a parity class survives exactly when

\[
\boxed{
\rho_k(w)\le\Theta_k(w).
}
\]

---

## 6. Monotone boundary gap

Define

\[
\boxed{
\Delta_k(w):=\Theta_k(w)-\rho_k(w)
}
\]

when \(\Theta_k<\infty\).

Along a fixed path,

\[
\rho_k\text{ is nondecreasing},
\qquad
\Theta_k\text{ is nonincreasing},
\]

so

\[
\boxed{
\Delta_{k+1}\le\Delta_k.
}
\]

The path is eliminated as soon as

\[
\boxed{\Delta_k<0.}
\]

If \(\Delta_k\ge0\) but finite, the number of unresolved starts in the class is

\[
\boxed{
1+\left\lfloor\frac{\Delta_k}{2^k}\right\rfloor.
}
\]

Hence finite-ceiling channels collapse toward a singleton automatically as the dyadic spacing grows unless the class is eliminated first.

---

## 7. Counterexample characterization

A positive integer counterexample to first descent exists iff there is an infinite realizable parity path \(w_1\prec w_2\prec\cdots\) such that

\[
\boxed{
\rho_k(w_k)\le\Theta_k(w_k)
\quad\text{for every }k,
}
\]

and the formation floor remains bounded.

Because \(\rho_k\) is integer-valued and nondecreasing, boundedness forces eventual stabilization at a finite integer \(n\). The counterexample condition then becomes

\[
\boxed{
\Theta_k(w_k)\ge n
\quad\text{for every }k.
}
\]

Thus the universal proof problem is a monotone-boundary crossing problem:

> prove that no finite-natural-realizable infinite path can keep the decreasing survival ceiling above its eventually constant formation floor forever.

This is the preferred set-theoretic statement for future property filters.

---

## 8. Role of previous attributes

The previous candidate attributes now have precise roles:

- coefficient balance determines whether a new ceiling is created;
- correction/headroom determines the value of the new ceiling;
- residue/lift/valuation data determine the formation floor and which prefix extensions are realizable;
- macroblock and CRT data are compressed formation filters for long parity runs;
- generating mass is an optional global certificate obtained by summing the exact survivor cylinders.

The proof should therefore seek classwise inequalities forcing the formation floor upward or the survival ceiling downward until the two cross, rather than enumerating starting integers.
