## 5. Exact reverse carry description of every odd-root boundary factor

Consider one deterministic plateau-pair factor at its own effective dyadic modulus

\[
M_j=2^{L+1-j}.
\]

After the ordinary 2-adic valuation projection, work with its odd root frequency \(u\).  Define

\[
b_0^{(j)}=\operatorname{cent}_{M_j}(u),

and the inverse-three centered orbit

\[
3b_{r+1}^{(j)}
=b_r^{(j)}+d_r^{(j)}M_j,
\qquad
 d_r^{(j)}\in\{-1,0,1\}.
\]

If the one ordinal of the plateau coordinate is \(\ell_j\), then the boundary factor

\[
\left|
\cos\!\left(
\pi u
\frac{[3^{-\ell_j}]_{M_j}}{M_j}

\[
\boxed{
\left|
\cos\!\left(

The modulus varies with the plateau coordinate.  Therefore this identity is applied **factor by factor at the correct effective resolution**; one must not silently place all plateau factors in a single fixed modulus.

## 6. Boundary weakness is a reverse zero-carry condition

Fix an integer \(s\ge1\).  For a plateau coordinate with \(\ell_j\ge s\), the following are equivalent:

\[

\[

Thus a boundary factor can remain very close to one only when the corresponding reverse carry word ends with a long zero suffix.

## 7. Combined pointwise carry cost on one boundary cube

Let \(F\) be the mixed plateau-coordinate set of one exact boundary hypercube fibre.

For fixed \(s\), define

\[
A_s(u;F)
:=
\#\left\{
 j\in F:
(d_{\ell_j-s}^{(j)},\ldots,d_{\ell_j-1}^{(j)})
\ne(0,\ldots,0)
\right\},
\]

counting only coordinates with \(\ell_j\ge s\).

Every coordinate counted by \(A_s\) contributes a boundary factor strictly below \(\theta_s\).  Hence the exact cube factorization gives

\[
\boxed{
\prod_{j\in F}
\left|
\cos\!\left(
\pi u
\frac{[3^{-\ell_j}]_{M_j}}{M_j}
\right)
\right|
\le
\theta_s^{A_s(u;F)}.
}
\]

Combining this with selector attenuation gives the pointwise joint bound

\[
\boxed{
|P_{m,L}(u)|
\prod_{j\in F}|B_j(u)|
\le
\left(\frac{\sqrt3}{2}\right)^{C_m^+(u)}
\theta_s^{A_s(u;F)}.
}
\]

Equivalently, define the nonnegative carry cost

\[
\boxed{
\mathcal Q_{m,F,s}(u)
:=
C_m^+(u)\log\!\frac{2}{\sqrt3}
+
A_s(u;F)\left[-\log\theta_s\right].
}
\]

Then

\[
\boxed{
|P_{m,L}(u)|
\prod_{j\in F}|B_j(u)|
\le e^{-\mathcal Q_{m,F,s}(u)}.
}
\]

This is the current natural common descriptor for selector/boundary complementarity.

## 8. The next proof-level theorem

The principal target can now be stated without assuming independence.

### Strong pointwise version

Find fixed \(s\) and \(c_*>0\) such that, on every relevant large scale and every nonexceptional boundary cube with linearly many mixed plateau coordinates,

\[
\boxed{
\mathcal Q_{m,F,s}(u)\ge c_*L
}
\]

for every relevant odd root frequency \(u\).

This would force exponential decay of the joint selector/boundary contribution.

### Weaker weighted version

It is enough to prove an averaged or exceptional-set estimate strong enough for the spectral-exception splitting lemma, for example

\[
\boxed{
\sum_{u\in\mathcal E_m}
 e^{-\mathcal Q_{m,F,s}(u)}
\le e^{-c_*L}
}
\]

with the correct normalization, uniformly over the boundary fibres generated in the spectral genealogy.

The weighted version is likely more realistic because exact pointwise incompatibility may fail on a small arithmetic family.
