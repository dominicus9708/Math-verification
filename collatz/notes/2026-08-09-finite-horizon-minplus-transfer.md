# Finite-horizon min-plus transfer on the E/O count plane

Date: 2026-08-09

Status: **DERIVED LEMMA + EXACT DYNAMIC PROGRAM + COMPLEXITY BOUND**

This note turns the safe finite-horizon cylinder dominance lemma into an exact transfer operator for the minimal coefficient-survivor function

\[
\mu(K)=\min\{n\ge1:\tau_c(n)>K\}.
\]

It is a target-specific finite computation.  It is not an asymptotic Collatz proof.

## 1. Coarse plane and finite carry fiber

At depth `k`, let

\[
q=q_k
\]

be the odd count and let

\[
m=K-k
\]

be the remaining horizon to the fixed target `K`.

The E/O count-plane coordinate is `(k,q)`.
For exact future carry behavior through the remaining `m` steps, the full endpoint `y` can be replaced by

\[
\boxed{\eta=y\bmod2^m.}
\]

For the same-q quotient, `3^q mod 2^m` is determined by `q`, so the exact finite-horizon state is

\[
\boxed{(q,\eta)}
\]

with a min-plus value

\[
\boxed{D_k(q,\eta)=\min r,}
\]

the smallest canonical start among all surviving depth-`k` prefixes having that signature.

The finite-horizon dominance lemma proves that discarding all larger `r` values in the same `(q,eta)` class is exact for this fixed target `K`.

## 2. One-step transfer

Suppose the remaining horizon is `m>=1` and choose the next requested parity

\[
b\in\{0,1\}.
\]

Set

\[
g=[3^q]_{2^m},
\]

and define the canonical lift bit

\[
\boxed{c=b\oplus(\eta\bmod2).}
\]

The lifted endpoint residue is

\[
z=\eta+cg\pmod{2^m}.
\]

By construction `z` has parity `b`.
The next odd count is

\[
q'=q+b.
\]

The next endpoint residue modulo `2^{m-1}` is

\[
\boxed{
\eta'=
\begin{cases}
 z/2,&b=0,\\[2mm]
 (3z+1)/2,&b=1,
\end{cases}
\pmod{2^{m-1}}.
}
\]

The min-plus edge cost is exactly the newly exposed binary lift digit:

\[
\boxed{w_k=c2^k.}
\]

The transition is retained only if the coefficient barrier survives:

\[
\boxed{3^{q'}\ge2^{k+1}.}
\]

Equivalently, with

\[
a_j=\lceil j\log_3 2\rceil,
\]

require

\[
q'\ge a_{k+1}.
\]

## 3. Exact min-plus recurrence

Write `infinity` for an absent state.  Then

\[
\boxed{
D_{k+1}(q',\eta')
=
\min_{
(q,\eta,b)\to(q',\eta')
}
\left(D_k(q,\eta)+c2^k\right).
}
\]

The initial condition is

\[
D_0(0,0)=0.
\]

At the target depth, `m=0`, so the endpoint modulus is trivial and

\[
\boxed{
\mu(K)=\min_q D_K(q,0).
}
\]

Thus the minimal-survivor problem is an exact nonstationary min-plus matrix product whose E/O channels carry costs `0` or `2^k`.

## 4. Matrix form

For each depth `k` and remaining horizon `m=K-k`, let

\[
\mathcal I_{k,m}
=
\{(q,\eta):q\ge a_k,\ 0\le\eta<2^m\}.
\]

Define two sparse rectangular min-plus matrices

\[
\mathcal T^{(0)}_{k,m},
\qquad
\mathcal T^{(1)}_{k,m}
\]

for the E and O channels.
For an allowed transition generated by parity `b`, the corresponding matrix entry is

\[
\boxed{c2^k;}
\]

all other entries are `+infinity`.

Then

\[
D_{k+1}
=
\left(\mathcal T^{(0)}_{k,m}\oplus
      \mathcal T^{(1)}_{k,m}\right)
\otimes D_k
\]

in the min-plus semiring, where `oplus=min` and `otimes=+`.

This is the precise matrix realization of the current two-channel E/O picture:

- E/O count plane: `(k,q)`;
- finite carry channel: `eta`;
- min-plus cost channel: canonical start `r`.

## 5. Stronger Pareto signature

The cross-q finite-horizon lemma uses

\[
\boxed{
(\eta,g)
=
(y\bmod2^m,\ 3^q\bmod2^m).
}
\]

Within one `(eta,g)` class, a state `(r_1,q_1)` dominates `(r_2,q_2)` for the fixed horizon whenever

\[
r_1\le r_2,
\qquad
q_1\ge q_2.
\]

Therefore one may retain only the `(r,q)` Pareto frontier in each `(eta,g)` class.
This can merge different odd-count layers near the terminal end where the multiplicative order of `3 mod 2^m` is small.

The simpler `(q,eta)` quotient is easier to audit and is the reference implementation in

## 6. Exact state-count upper bound

Let `P_k` denote the set of coefficient-surviving parity prefixes of length `k`.
The quotient state count `N_k(K)` obeys two immediate bounds:

\[
N_k(K)\le |P_k|
\]

and

\[
N_k(K)\le(k+1)2^{K-k},
\]

because there are at most `k+1` possible odd counts and `2^{K-k}` endpoint residues.

Let

\[
\alpha=\log_3 2
\]

and

\[
H=H_2(\alpha)
=-\alpha\log_2\alpha-(1-\alpha)\log_2(1-\alpha)
\approx0.9499555271883306.
\]

Ignoring the prefix barrier only enlarges the survivor language, so the usual binary-tail bound gives

\[
|P_k|
\le
(k+1)2^{Hk}.
\]

Hence

\[
\boxed{
N_k(K)
\le
(k+1)\min\left(2^{Hk},2^{K-k}\right).
}
\]

The two exponential envelopes cross near

\[
\boxed{
\frac{k}{K}=\frac1{1+H}
\approx0.5128322088,
}
\]

where the exponent is

\[
\boxed{
\frac{H}{1+H}K
\approx0.4871677912K.
}
\]

Thus this exact quotient gives a worst-envelope exponent below `K/2`, up to polynomial factors, compared with flat `2^K` parity enumeration.
This is a computational complexity reduction, not a convergence theorem.

## 9. What remains hard

The quotient is exact but still potentially exponential.  The main unresolved structural question is whether the `(q,eta)` or `(eta,g)` state set admits a further **uniform** contraction that preserves the min-plus minimum without retaining exponentially many endpoint cylinders.

Any such contraction must be proved against the exact finite-horizon operator.  The earlier failed endpoint-only and slack-only merges show that an unproved dominance rule can silently delete the true minimizer.

The next safe target is therefore a certified block or interval dominance rule on the low-bit carry states, not another scalar average or single-boundary approximation.
