# MATH-118 — first-return paid-count partition lemma

Status: `MAINLINE COVERAGE LEMMA / PARTIAL STAGE-B AUDIT / NO NEW LOWER-r CLOSURE CLAIM`

Date: 2026-09-14

## Motivation

After MATH-111 closes `r=12`, it is tempting to ask whether lower layers are nested inside the already closed higher layers. The MATH-065 state machine shows that this is not the semantics of the paid-count index.

The `r` layers are **first-return paid-count classes**.

## Exact state semantics

Inside `negative_candidate_cylinders(cell,r)`, a branch state carries

```text
(j, u, ...)
```

where:

- `j` is the number of paid odd shortcut steps already taken in the current paid excursion;
- `u` is the current unresolved return-depth counter;
- the opening state is `(j,u)=(0,1)`;
- a paid odd transition changes `j -> j+1` and `u -> u+eps[j]`;
- an even shortcut transition leaves `j` fixed and changes `u -> u-1`;
- transitions are generated only while `u>0`.

The implementation contains the exact terminal rule:

```python
if u == 0:
    if j == r:
        ... materialize completed cylinder ...
    # u=0 before j=r is an earlier return, not an r-paid cluster.
    continue
```

Thus the first hit of `u=0` ends the current paid excursion.

## Lemma

Fix one macro start and one exact ordinary-integer/address lineage. Suppose its paid excursion has a finite first return to `u=0`.

Let

```text
r_* = number of paid odd shortcut steps completed before that first return.
```

Then `r_*` is unique.

### Proof

Along one deterministic ordinary-integer lineage, `j` starts at zero and changes only by `+1` on paid odd transitions. The first state with `u=0` is unique by definition of first hitting time. Therefore the value of `j` at that state is a unique integer `r_*`.

The MATH-065 `r`-layer accepts the lineage exactly when the first `u=0` state occurs with `j=r`; if `u=0` occurs at any `j<r`, that branch is explicitly terminated as an earlier return.

Hence one finite-return paid excursion cannot simultaneously belong to two different `r` layers.

QED.

## Consequences

For the multi-paid families covered by the MATH-065 semantics:

```text
C_r ∩ C_s = empty    for r != s
```

at a fixed macro start/address lineage, where `C_r` denotes excursions whose first return occurs after exactly `r` paid odd transitions.

Therefore closure is **not monotone by set inclusion**:

```text
r=12 CLOSED  does not imply  r=11 CLOSED,
r=13 CLOSED  does not imply  r=12 CLOSED,
```

and so on.

This explains why the lower layers still require either:

1. their own exact closure certificates; or
2. a genuinely uniform theorem quantified over `r` (or over an invariant common to all first-return classes).

## Partial Stage-B coverage result

MATH-118 resolves one part of the later coverage audit:

- distinct finite first-return paid-count labels do not overlap;
- any finite-return excursion with first-return count `r_* >= 2` has at most one multi-paid layer label.

It does **not yet** prove the full union is exhaustive for the first-cell proof reduction. The following remain separate obligations:

1. determine the exact role of `r=0`;
2. identify whether `r=1` is exactly the already-audited one-paid family or requires a translation lemma;
3. audit any possible excursion that does not return to `u=0` within the semantic domain being reduced;
4. connect the paid-excursion partition back to every first-cell ordinary-integer address lineage.

## General-closure search constraint

Because the `C_r` are disjoint first-return classes rather than nested sets, a useful lower-layer generalization must look schematically like

```text
For every r in a proved range,
for every exact AP source generated by the r-first-return classifier,
a common invariant V decreases / enters the frozen floor under exact AP propagation.
```

A proof based only on `C_{r-1} subset C_r` or the reverse inclusion is invalid.

## Claim boundary

MATH-118 is a semantic/coverage lemma. It does not close `r=11`, `r=10`, any lower layer, the first universal Farey cell, or Collatz.
