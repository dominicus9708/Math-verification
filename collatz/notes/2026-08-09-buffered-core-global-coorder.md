# Buffered-core global co-order reduction

Date: 2026-08-09

Status: derived structural lemma for the finite first-coefficient-crossing branch. This is not a proof of the Collatz conjecture or of coefficient-stopping equality.

## Setup

Use the accelerated Collatz map

\[
T(n)=\begin{cases}
n/2,&n\text{ even},\\
(3n+1)/2,&n\text{ odd}.
\end{cases}
\]

At first coefficient crossing with `q` odd entries, let

\[
\sigma=\lceil q\log_2 3\rceil,\quad
M=2^\sigma,\quad P=3^q,\quad D=M-P>0.
\]

For an admissible odd-position vector
\[
\alpha=(\alpha_1<\cdots<\alpha_q),
\]
write
\[
R(\alpha)=\sum_{i=1}^{q}3^{q-i}2^{\alpha_i}.
\]
If `x` is its canonical start modulo `M`, `y=T^sigma(x)`, and `z=x-y`, then
\[
My=Px+R,\qquad Mz=Dx-R.
\]

First-coefficient admissibility gives
\[
\alpha_i\le \lfloor(i-1)\log_2 3\rfloor.
\]

## Lemma 1: tail difference size

Suppose two admissible vectors `alpha,beta` agree in their first `B` odd positions. For every `i>B`, strict increase gives
\[
\alpha_i,\beta_i\ge i-1\ge B.
\]
Hence
\[
2^B\mid \Delta R.
\]
Also
\[
2^{\alpha_i},2^{\beta_i}<3^{i-1},
\]
so each tail summand difference has magnitude less than `3^(q-1)`. Therefore
\[
|\Delta R|<(q-B)3^{q-1}\le q3^{q-1}.
\]

## Lemma 2: start difference divisibility

Since
\[
P\Delta x+\Delta R\equiv0\pmod M
\]
and `P` is odd, reduction modulo `2^B` gives
\[
2^B\mid\Delta x.
\]
Thus for distinct canonical states,
\[
|\Delta x|\ge2^B.
\]

## Buffered-core global co-order lemma

Choose `B` so that
\[
D2^B>q3^{q-1}.
\]
Then for two states in the same `B`-core fiber,
\[
M\Delta z=D\Delta x-\Delta R.
\]
If `Delta x>0`,
\[
M\Delta z\ge D2^B-|\Delta R|>0.
\]
The reversed pair handles `Delta x<0`. Hence
\[
\boxed{\operatorname{sgn}(\Delta z)=\operatorname{sgn}(\Delta x)}.
\]
Equivalently,
\[
\boxed{x_1<x_2\iff z_1<z_2}
\]
for every pair sharing the first `B` odd positions.

This is a global pairwise statement and does not require a unique-sink property of the local move graph.

## Same B also bounds a paradoxical start

A paradoxical first coefficient crossing satisfies `y>=x`, so from
\[
Mz=Dx-R\le0
\]
we have
\[
Dx\le R.
\]
Using the normalized correction bound
\[
R<q3^{q-1},
\]
we get
\[
\boxed{x<\frac{q3^{q-1}}D}.
\]
Therefore the same condition
\[
D2^B>q3^{q-1}
\]
implies
\[
\boxed{x<2^B}.
\]
The first `B` parity bits uniquely determine `x mod 2^B`; because `0<x<2^B`, they determine `x` itself. Thus a hypothetical first-crossing counterexample has no independent tail realization freedom after its first `B` parity bits are fixed.

## Exact minimal buffered core

One may take the least integer
\[
B(q)=\min\{B\ge0:D2^B>q3^{q-1}\}.
\]
Equivalently, writing
\[
\theta_q=\sigma-q\log_2 3,
\qquad D=3^q(2^{\theta_q}-1),
\]
we need
\[
2^B>\frac{q}{3(2^{\theta_q}-1)}.
\]

## Logarithmic core size from a linear-form lower bound

Rozier--Terracol quote a global lower bound of the form
\[
|\sigma\log2-q\log3|\ge \sigma^{-13.3}.
\]
Since
\[
2^{\theta_q}-1=e^{\sigma\log2-q\log3}-1
\ge \sigma\log2-q\log3,
\]
we obtain
\[
\frac{q}{3(2^{\theta_q}-1)}
<\frac{q\sigma^{13.3}}3
<\sigma^{14.3}.
\]
Hence one may choose
\[
\boxed{B(q)\le\lceil14.3\log_2\sigma\rceil}.
\]
Thus the number of independent parity bits needed to specify a hypothetical first-crossing counterexample is logarithmic in the nominal crossing length.

## Consequence for the proof program

The previously proposed DCER/unique-sink route is unnecessarily strong. The safe tail can instead be removed by a magnitude-plus-divisibility argument:

1. choose the logarithmic buffered core `B(q)`;
2. within each B-core fiber, x and z have identical total order;
3. a paradoxical start must satisfy x<2^B;
4. its first B parity bits therefore determine x exactly;
5. the remaining parity tail is generated by that integer and is not an independent search axis.

The unresolved issue is still global in q: this reduction does not prove that no such polynomial-size canonical start exists for arbitrarily large first-crossing order.
