# Ordering-only Bellman relaxation and weighted histogram compression

Date: 2026-08-27

Status: **SAFE abstract lower-bound lemma.**  This note proves the symbolic ordering-only relaxation for every finite mechanical gap word.  It does **not** identify the exact Hensel cost, does not close the first-resonance branch, and does not prove the Collatz conjecture.

## 1. Setup

Traverse a finite mechanical gap word from right to left,

\[
w=(g_1,\ldots,g_h),\qquad g_i\in\{1,2\}.
\]

Let the right-boundary displacement be \(p\ge0\).  Drop the Hensel carry/congruence condition and retain only the ordering constraint.  If the current displacement is \(p_{i-1}\), the next displacement \(d_i=p_i\) must satisfy

\[
p_i\ge L_i:=\max\{0,p_{i-1}-g_i+1\}.
\]

Normalize the right-boundary weight by \(w_0=1\), and define

\[
w_i=w_{i-1}\frac{3}{2^{g_i}}.
\]

The local real cost is

\[
\kappa_i(d)=2w_i(1-2^{-d}).
\]

For fixed \(i\), \(\kappa_i(d)\) is strictly increasing in the integer displacement \(d\ge0\).

## 2. Greedy optimum is globally exact for the relaxation

Define the greedy recursion

\[
\boxed{
p_i=\max\{0,p_{i-1}-g_i+1\}.}
\]

This choice minimizes the current local cost because \(\kappa_i\) is increasing.  It also minimizes the next boundary displacement.  A smaller next displacement weakly lowers every future ordering lower bound, so it cannot increase the minimum future relaxed cost.

Induction on the remaining word length therefore proves that the greedy choice is globally optimal for the ordering-only problem.

Since a gap \(g_i=1\) leaves the positive displacement unchanged and a gap \(g_i=2\) lowers it by one until zero, if

\[
c_i:=N_2(g_1,\ldots,g_i)
\]

is the number of 2-gaps in the first \(i\) letters, then

\[
\boxed{
p_i=\max\{0,p-c_i\}.}
\]

Consequently the exact relaxed boundary transform is

\[
\boxed{
F_w(p)=\max\{0,p-N_2(w)\}.
}
\]

## 3. Ordering-only Bellman cost

Define

\[
\boxed{
B_w(p)=\sum_{i=1}^h 2w_i\left(1-2^{-p_i}\right),
\qquad p_i=\max\{0,p-c_i\}.
}
\]

Every exact Hensel/ordering path is also an ordering-only path.  Dropping the Hensel congruence therefore enlarges the feasible set.  Hence, for any exact Hensel boundary problem whose right displacement is \(p\),

\[
\boxed{
\mathcal T_w^{\rm Hensel}\ge B_w(p),
}
\]

whenever the left boundary is also relaxed in the comparison.  This is a lower bound only; equality is not claimed.

## 4. Exact block composition

Let \(w=uv\), with \(u\) traversed first.  Put

\[
\lambda(u)=\prod_{g\in u}\frac3{2^g}.
\]

The greedy state transform composes exactly:

\[
\boxed{
F_{uv}(p)=F_v(F_u(p)).
}
\]

The reference weights in \(v\) are scaled by \(\lambda(u)\), so

\[
\boxed{
B_{uv}(p)
=
B_u(p)+\lambda(u)B_v(F_u(p)).
}
\]

Also

\[
\boxed{
\lambda(uv)=\lambda(u)\lambda(v).
}
\]

Thus the ordering-only block is summarized exactly by

\[
\boxed{(F_w,B_w,\lambda_w).}
\]

## 5. Weighted 2-gap histogram

The Bellman function admits a more useful representation.  Group all local weights by the accumulated number of 2-gaps:

\[
\boxed{
A_c(w):=\sum_{i:\,c_i=c}2w_i.
}
\]

Because the term at step \(i\) vanishes whenever \(c_i\ge p\),

\[
\boxed{
B_w(p)
=
\sum_{c=0}^{p-1}
A_c(w)\left(1-2^{-(p-c)}\right).
}
\]

Therefore the entire relaxed Bellman function is a fixed geometric cumulative transform of the nonnegative histogram \(A_c(w)\).

### 5.1 Discrete derivative

Define

\[
H_p(w):=\sum_{c=0}^{p}A_c(w)2^{-(p-c)}.
\]

Direct subtraction gives

\[
\boxed{
B_w(p+1)-B_w(p)=\frac12 H_p(w).
}
\]

The geometric kernel itself obeys

\[
\boxed{
H_{p+1}(w)=A_{p+1}(w)+\frac12H_p(w).
}
\]

Hence \(B_w\) is monotone in \(p\), with its increments generated by a first-order geometric filter.

## 6. Histogram composition and generating function

Let

\[
r=N_2(u).
\]

A step belonging to \(v\) sees \(r\) previous 2-gaps and its mechanical weight is multiplied by \(\lambda(u)\).  Therefore, with out-of-range histogram entries interpreted as zero,

\[
\boxed{
A_c(uv)
=
A_c(u)+\lambda(u)A_{c-r}(v).
}
\]

Define the polynomial/formal series

\[
\mathcal A_w(z)=\sum_{c\ge0}A_c(w)z^c.
\]

Then the preceding identity is equivalent to

\[
\boxed{
\mathcal A_{uv}(z)
=
\mathcal A_u(z)
+
\lambda(u)z^{N_2(u)}\mathcal A_v(z).
}
\]

Together with

\[
N_2(uv)=N_2(u)+N_2(v),
\qquad
\lambda(uv)=\lambda(u)\lambda(v),
\]

this gives an exact algebraic block composition compatible with Euclidean/Christoffel word recursion.  It avoids enumerating the full \(A_0\)-scale word merely to establish the abstract relaxation.

## 7. Relation to the Hensel problem

The relaxation deliberately deletes the carry \(K\) and the congruence

\[
K+2^{e_i-d_i}\equiv0\pmod3.
\]

That deletion can only lower the minimum, which is why \(B_w\) is safe as a lower bound.  The deletion is also severe: in particular

\[
B_w(0)=0.
\]

Therefore ordering alone cannot uniformly close a Hensel cost budget when boundary states with \(p=0\) remain possible.  A residue-sensitive strengthening is necessary.

The correct next refinement is finite-horizon only: enforce exact Hensel transitions for a fixed number \(m\) of steps, then relax the remaining tail back to \(B\).  Fixed \(K\bmod3^m\) information may be used for those \(m\) controlled steps, but not as an exact quotient for an unbounded continuation.

## 8. DSD structural chain

\[
\boxed{
(K,p)\text{ exact Hensel state}
\longrightarrow
p\text{-only ordering relaxation}
\longrightarrow
c_i=N_2(\text{prefix})
\longrightarrow
A_c
\longrightarrow
(F,B,\lambda)
\longrightarrow
\text{block-composable lower potential}.
}
\]

This is deliberate information deletion with a certified monotone direction: removing a constraint enlarges the feasible set, hence decreases the minimum.  The DSD role of \(A_c\) is a sufficient descriptor for the relaxed cost, not a sufficient descriptor for the exact Hensel dynamics.

## 9. Structural audit

### SAFE

- greedy optimality for the ordering-only problem;
- \(F_w(p)=\max(0,p-N_2(w))\);
- exact \((F,B,\lambda)\) block composition;
- weighted histogram representation of \(B_w\);
- discrete derivative/geometric-filter recurrence;
- exact histogram/generating-function block composition;
- \(\mathcal T^{\rm Hensel}\ge B\) after the corresponding boundary relaxation.

### REJECTED

- interpreting \(B_w\) as the exact Hensel cost;
- using the p-only relaxation to infer a 3-adic congruence;
- using a fixed \(K\bmod3^m\) quotient as an exact state beyond its controlled horizon;
- treating the finite regression script as the proof of these all-word identities.

### OPEN

- whether the ordering-only lower bound is already useful for particular nonzero boundary p ranges;
- a finite-depth Hensel-residue strengthening \(B^{(m)}\);
- an efficient Christoffel recursion for evaluating the residue-sensitive refinement at first-resonance scale;
- comparison of the refined Hensel lower cost with the independent near-root defect budgets.
