# Surplus First-Divergence Stage Audit

Date: **2026-09-05**

**Status:** CONTROL DIVERGENCE LOCATED / FIRST PROVED ORDINARY-SOURCE DIVERGENCE OPEN

## 1. Audit question

The purpose of this audit is to distinguish two questions that must not be conflated:

1. At what stage do the low-surplus constructions first carry different **checkpoint/control data**?
2. At what stage has the proof actually established different **ordinary-source branches**?

These are different claims.

The first may be visible in a checkpoint coordinate. The second requires a source/orbit predicate and same-source realization theorem.

## 2. Audit layers

Use the DSD order

\[
\boxed{
L0\ \text{ordinary source/orbit}
\to
L1\ \text{checkpoint applicability and realization}
\to
L2\ \text{checkpoint/control representation}
\to
L3\ \text{derived completion}.
}
\]

A genuine branch of ordinary Collatz starts must be definable at L0, possibly through a theorem connecting L1/L2 observations back to L0.

## 3. Stage D0 — ordinary source/orbit

Let \(x\in\mathbb N_{>0}\) be an ordinary source and \(\mathcal O_x\) its deterministic Collatz orbit.

At this stage, the currently inspected low-surplus certificate files do **not** yet provide distinct exact source predicates

\[
P_{s_1}(x,\mathcal O_x),\qquad P_{s_2}(x,\mathcal O_x)
\]

whose source domains have been proved to be the exact realizations of distinct surplus sectors.

### Verdict

\[
\boxed{\text{no first ordinary-source divergence is proved at D0.}}
\]

Status: **OPEN**.

## 4. Stage D1 — checkpoint existence, prerequisites, and realization

Before surplus can be evaluated as a branch coordinate, the relevant checkpoint must exist for the source under consideration and its prerequisites must be satisfied.

The source/checkpoint association should be represented explicitly by

\[
R(x,\sigma),
\]

meaning that checkpoint state \(\sigma\) is generated by the same ordinary source/orbit \(x\).

The proof must distinguish:

- not applicable / prerequisite unsatisfied;
- applicable but undefined;
- defined zero;
- defined nonzero/value-bearing.

A global theorem showing that every candidate counterexample reaches the required checkpoint interface in exactly the manner needed for the surplus classification has not yet been established in the canonical stack.

### Verdict

Status: **GLOBAL APPLICABILITY / REALIZATION OPEN**.

## 5. Stage D2 — checkpoint surplus

Canonical audit notation is

\[
\boxed{s_{\mathrm{cp}}:=\text{tenth-checkpoint surplus}.}
\]

The directly inspected Xi/checkpoint note records the local `s=1` condition

\[
\boxed{\tau_{j_0}\le t_0<\tau_{j_0+1}.}
\]

The low-surplus certificates then admit different values of `s` as checkpoint-control inputs.

Therefore the **earliest directly evidenced difference among the inspected low-surplus control states is the value of**

\[
\boxed{s_{\mathrm{cp}}.}
\]

This is a difference at the checkpoint/control layer.

It is not yet, by itself, a proof that ordinary sources decompose into exact branches indexed by \(s_{\mathrm{cp}}\).

### Verdict

\[
\boxed{\text{first directly supported control divergence}=s_{\mathrm{cp}}.}
\]

Status: **LOCATED AT L2, CONDITIONAL ON L1 REALIZATION**.

## 6. Stage D3 — deterministic surplus displacement

The directly inspected low-surplus certificate family uses

\[
\boxed{r=s_{\mathrm{cp}}-1},
\]

where `r` is interpreted there as the number of extra odd ordinals crossed to the left of `T0`.

Once \(s_{\mathrm{cp}}\) is fixed, `r` is determined.

Therefore a difference in `r` is not an independent second branching event. It is a deterministic propagation of the D2 checkpoint-control difference.

### Verdict

\[
\boxed{r\text{ does not define an independent branch.}}
\]

Status: **DERIVED CONTROL COORDINATE**.

## 7. Stage D4 — surplus-tax, packed suffix, Hensel budget, and envelope consequences

The low-surplus certificate family computes later quantities such as checkpoint taxes, packed counts/losses, effective budgets, or envelope bounds from the already chosen low-surplus/control state.

These quantities can differ between surplus inputs, but their difference is downstream of D2/D3.

They therefore cannot be counted as independent filters or as evidence of an earlier branch origin.

In particular:

\[
\text{different budget/envelope value}
\not\Rightarrow
\text{different ordinary-source branch}
\]

without a separate source-realization theorem.

### Provenance correction

A relation previously recorded as

\[
q_\star=Q0-r
\]

was not recovered in the directly inspected current canonical certificate files.

It is excluded from the current canonical dependency chain.

Likewise,

\[
s_{\mathrm{cp}}=A_0-j_\star
\]

is not currently established as an ordinary-orbit identity.

### Verdict

Status: **DOWNSTREAM CONTROL/DERIVED CONSEQUENCES; NOT SOURCE-BRANCH ORIGIN**.

## 8. Stage D5 — required reflection to ordinary source

This is the first unresolved stage at which the checkpoint/control difference must be promoted back to an ordinary-source statement.

Let \(\Sigma_s\) be the checkpoint-state space, \(A_s(\sigma)\) its exact admissibility predicate, and \(R(x,\sigma)\) the same-source realization relation.

Construct exact source charts

\[
\Phi_{s,\lambda}:I_{s,\lambda}\to\mathbb N
\]

and domains

\[
\mathcal D_s
=
\bigcup_\lambda \Phi_{s,\lambda}(I_{s,\lambda}).
\]

The required forward theorem is

\[
\boxed{
A_s(\sigma)\land R(x,\sigma)
\Longrightarrow
x\in\mathcal D_s.
}
\]

If \(\mathcal D_s\) is used as an exact branch, require reflection:

\[
\boxed{
x\in\mathcal D_s
\Longrightarrow
\exists\sigma\in\Sigma_s:\ A_s(\sigma)\land R(x,\sigma).
}
\]

Only after these implications are proved can surplus sectors be written as actual source branches

\[
B_s:=\{x:P_s(x,\mathcal O_x)\}.
\]

### Verdict

\[
\boxed{\text{first proved source-level divergence}=\text{OPEN}.}
\]

The missing theorem lies at the L1/L2-to-L0 reflection/transport interface.

## 9. Exact first-divergence criterion for future closure

To claim that stage \(k\) is the first true ordinary-source divergence between two surplus sectors \(s_1\ne s_2\), prove all of the following:

1. **common provenance before \(k\):** all earlier compared states arise from the same source-compatible construction;
2. **exact source predicates at \(k\):** there exist predicates \(P_{s_1}^{(k)}\), \(P_{s_2}^{(k)}\) on ordinary source/orbit data;
3. **transport:** the checkpoint/control states at \(k\) are equivalent to those source predicates on their stated domains;
4. **non-equivalence:** the source predicates are genuinely different;
5. **coverage/accounting:** every admitted source is assigned correctly, with overlap or disjointness proved rather than assumed.

If disjoint sectors are claimed, prove

\[
B_{s_1}\cap B_{s_2}=\varnothing.
\]

If overlap is allowed, record it explicitly.

## 10. External finite-range consequence

The existing external finite-range closure can only be used after D5 gives an ordinary-source domain theorem.

For a transported surplus sector, a sufficient interface is

\[
\mathcal D_s\subseteq[1,L_{RS}],
\]

where

\[
L_{RS}=4\cdot3^{44}+2
=3{,}939{,}083{,}608{,}734{,}444{,}931{,}526.
\]

Then, on the declared external-dependency path, that **source sector** may inherit finite-range closure.

No budget/envelope comparison alone licenses this step.
