# Forbidden shortcuts

The following do not belong in the canonical implication chain:

- `adic mismatch => membership rejection`;
- interval inclusion => correction-language membership;
- endpoint residue exposure => same orbit;
- local carry greedy => global minimum defect without a fixed cylinder sequence;
- singleton exponent cylinder => singleton carry/grammar path;
- terminal residue exposure => carry that residue through the entire forward root scan before it is observable;
- multiplication of marginal survival ratios without independence;
- finite small-horizon agreement => universal theorem;
- `A0, s=1, Route-B` closure => Collatz without C0/C6.

Rejected routes remain valuable audit records but are kept outside this live stack.
