# Result data

This directory contains generated or recorded result data used by Collatz certificates and experiments.

## Classification rule

A result file is evidence only together with the certificate / exact derivation that defines how it was produced.

Do not treat a stored numerical table as an independent theorem.

## New result metadata

New result data should identify:

- producing certificate/script;
- producing commit;
- exact input domain;
- arithmetic mode;
- deterministic/exhaustive/sampled status;
- expected checksum or key invariant when practical;
- whether the result is canonical evidence or diagnostic only.
