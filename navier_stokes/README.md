# Navier–Stokes verification

3차원 비압축성 Navier–Stokes 존재성·정칙성 문제를 구조적으로 분석하기 위한 작업 디렉터리입니다.

이 디렉터리의 첫 단계는 **반지름 `R`인 3차원 구 내부**를 보조 테스트베드로 삼아, 중심부의 매끄러운 비압축성 초기 운동이 좌표축 성분과 구면 껍질 방향으로 어떻게 재배열되는지 분리하여 추적하는 것입니다.

> **범위 주의:** Clay의 공식 밀레니엄 문제는 `R^3` 또는 주기적 `R^3/Z^3`에서 제시됩니다. 유계 구 `B_R(0)`에서의 결과는 그 자체로 밀레니엄 문제의 증명이 아니며, 이후 `R`에 독립적인 추정·국소화·`R→∞` 극한 등의 연결 단계가 필요합니다.

## 기본 영역

\[
\Omega_R=B_R(0)=\{x\in\mathbb R^3:|x|<R\},
\qquad
\partial\Omega_R=S_R^2.
\]

기본 PDE는 외력 없는 비압축성 Navier–Stokes입니다.

\[
\partial_t u+(u\cdot\nabla)u=-\nabla p+\nu\Delta u,
\qquad
\nabla\cdot u=0,
\qquad
\nu>0.
\]

닫힌 구형 테스트베드의 1차 경계조건은 no-slip

\[
u|_{\partial\Omega_R}=0
\]

으로 둡니다. `R^3`의 일부를 단순 관측창으로 자르는 경우는 별도 트랙으로 분리합니다.

## 초기 운동

점원(point source)을 직접 두지 않고, 중심의 작은 구 `B_ε(0)` 안에 지지되는 `C^∞` 발산-없는 초기장을 사용합니다.

축 `a∈{x,y,z}`에 대한 기본 후보는

\[
u_0^{(a)}=\nabla\times\nabla\times\bigl(\psi(x)e_a\bigr),
\]

이며 `ψ`는 `B_ε(0)` 안에 지지되는 매끄러운 bump 함수로 둡니다. 이 구성은 `∇·u_0^{(a)}=0`을 자동으로 만족시키며, 세 축 실험은 구의 회전대칭 때문에 회전으로 서로 대응해야 합니다.

## 관측량

1. Cartesian 성분: `u_x, u_y, u_z`.
2. 반경·접선 분해: `u_r=u·e_r`, `u_t=u-u_r e_r`.
3. 구면 껍질 평균 운동에너지

\[
E(r,t)=\frac{1}{4\pi r^2}\int_{|x|=r}\frac12|u(x,t)|^2\,dS.
\]

4. 와도 `ω=∇×u`와 껍질 평균 enstrophy.
5. 압력 변동의 껍질 평균 및 각방향 편차.
6. 모든 `0<r<R`에서 순 방사 플럭스

\[
\Phi(r,t)=\int_{|x|=r}u\cdot n\,dS=0
\]

인지 확인합니다.

## '3차원 물결'의 의미

이 프로젝트의 비압축성 트랙에서 말하는 물결은 **음향파가 아니라 중심부 초기 운동에 따른 속도·압력·와도의 방사형 재배열/응답**입니다. 비압축성 Navier–Stokes의 압력 제약은 타원형이고 점성항은 포물형이므로, 실제 압축성 유체의 유한 속도 음향 파면과 동일시하지 않습니다.

실제 유한 전파속도의 압력파를 조사할 경우 `compressible/` 별도 트랙으로 분리하며, 그것을 Clay 문제의 직접 증명 단계와 혼합하지 않습니다.
